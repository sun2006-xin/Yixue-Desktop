# 译学学习工作台 v3 实现简报

## 产品意图

译学不是把四种功能堆在一起的工具箱，而是一个可恢复的学习桌面。用户可以只背词、只练句、只练发音，或只读文章；每条路径共享本地历史和词典，但互不设前置门槛。

## 本轮必须实现

1. 学习首页保留四张入口卡，视觉收敛，突出当前学习计划。
2. 词汇循环页改为“左叠卡选择范围＋右词库列表”；有搜索、展开详情、读音和收藏。
3. 句子练习独立进入；中译英不展示英文词块和序号，使用无编号方格输入。
4. 文章学习先选来源，选择后进入左原文/右译文与学习工具的双栏工作台。
5. 内置文章提供足够的段落内容用于验证工作台；外部文章保留合法导入/联网接入位，不自动复制或发布未授权内容。
6. 返回只改变页面，不结束学习会话；“退出本轮”才结束会话。

## 暂不伪装为已完成

真实网络文章爬取、文章级联网检索、AI 总结、音素级发音评分和全量 Oxford/CET/教材词库都继续走既有接口；本轮完成 UI、状态、入口和本地内容闭环。

## 验收流程

- Widget 测试：四卡独立进入、词库搜索/展开、句子不依赖词汇会话、文章来源到双栏工作台。
- 布局测试：桌面宽屏、窄窗口、列表空状态、长词条和长文章不溢出。
- 视觉审查：检查层级、密度、选中态、动效和深浅主题；不以“代码编译成功”替代实际 UI 验收。

## v3.1 页面层级落地约束（2026-09-17）

参考图中的四张界面不是一个合并页面，而是四条独立学习路径的页面参考：

`学习首页 → 词汇循环配置/词库浏览 → 词卡学习`

`学习首页 → 发音跟读配置 → 跟读学习`

`学习首页 → 句子练习配置 → 句子训练`

`学习首页 → 文章学习入口 → 通用阅读器`

学习首页和以上页面属于学习工作区内部，不能通过修改一级导航来代替。文章学习入口页保留阅读器学习模式主按钮，以及学习计划、阅读进度、收藏词汇、文章总结四个快捷入口；文章来源设置作为次要入口，不挤占主阅读路径。每条路径都可以直接打开、独立制定计划、恢复进度或退出本轮。
