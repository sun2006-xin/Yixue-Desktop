# 译学学习工作台 v3 设计系统

## 目标

把学习页做成“安静、清楚、能一直学下去”的学习桌面。页面以用户手绘的叠卡选择为核心：先选择学习方式或内容范围，再进入具体工作区；不把所有配置挤在同一张长卡片中。

## Colors

- `ink`: `#10202A`，标题和正文；避免大面积纯黑。
- `navy`: `#063B55`，品牌侧栏和深色工作台表头。
- `blue`: `#1768D5`，主要操作、选中状态、焦点环。
- `sky`: `#4EA7E8`，卡片上的轻微高光和进度轨道。
- `teal`: `#0B717B`，品牌结构色和文章工作台辅助色。
- `green`: `#23C692`，完成、已掌握和学习成长状态。
- `paper`: `#FBFDFE`，主要内容面板。
- `mist`: `#F1F6F8`，页面背景。
- `line`: `#D7E3E8`，边界和分割线。
- `muted`: `#6E7E88`，辅助说明和空状态。
- `danger`: 使用主题 error，仅用于真实失败，不用于未配置或待补充。

动效中蓝→青绿只用在当前选中范围或主按钮，普通内容卡片不铺渐变；渐变不可替代文字状态。

## Typography

- 沿用系统中文字体回退链，正文 15–16px，行高 1.45–1.6。
- 页面标题 28px/800，工作区标题 22px/800，卡片标题 16px/750，辅助文字 13px。
- 英文词条和文章使用 `serif` 或系统西文字体作为内容字体，保证词形和例句有阅读气质；中文 UI 不使用装饰字体。
- 同一页面最多使用 UI 字体和内容字体两种层级。

## Spacing

使用 4px 基线：4、8、12、16、24、32。桌面内容最大宽度 1320px，页面边距 28px；窄窗口降为 16px。卡片内部不低于 16px，主要工作区不低于 24px。

## Components

### Learning landing

- 顶部是一条轻量计划摘要：待复习数量、今日主线、目标进度和“继续/稍后”动作。
- 下方是四张等高功能卡片，采用 2×2 桌面网格、窄屏单列；每张卡片只有一个明显入口，不再把教材当第五种学习方式。
- 卡片使用 12px 圆角、1px `line`、低阴影；选中/悬停时向上 2px，边框变为 `blue`，只在当前卡片出现蓝绿细线。

### Vocabulary range deck

- 词汇循环选择页只显示居中的叠层学段卡片、左右切换、三条真实词条预览和“开始循环”。点学段卡片先选范围，开始按钮才创建对应词书的学习会话。
- “查看词库详情 / 查看全部”进入独立的可搜索列表页；该页可以返回词库选择。搜索、朗读、收藏仍沿用原词典数据。
- 学习设置由页头图标进入独立配置视图，保留题型、每日新词数和四六级切换；设置页不直接开学，返回选择页后再点击“开始循环”。
- 牌组显示小学、初中、高中、四六级、考研、牛津目标及全部词汇；数字来自当前本地词条，独立词表不存在时显示“待补充”并禁用开始。
- 词库选择页最大宽度 720px，当前卡片放在最前，其他卡片露出可点击的侧边；窄窗口压缩叠层间距，列表页单独滚动。

### Sentence practice

- 进入即能练习，不依赖词汇学习会话。
- 提示区只显示中文或英文的一侧；中译英时不显示英文词块、数字序号或标准答案提示。
- 输入格是无编号的等宽小方框，按英文词数动态生成；整句粘贴作为辅助入口放在“更多输入”中。

### Article source and workbench

- 文章学习入口先显示来源选择：网上公开内容、本地英文、本地中文、阅读器导入、内置内容、合法教材。
- 选中文章后，工作台桌面布局为左原文、右工具面板。右侧面板按当前选择切换：整篇译文、选词解释、例句、收藏/笔记、AI 总结。
- 左文支持段落选择、选词和批注锚点；右侧空状态必须说明“先选择词/段”，不显示无意义的空白大卡片。
- 网络来源只保留来源和用户主动导入接口；是否可以复制、缓存或随软件发布必须由许可证状态决定。

## States

- `idle`: 有明确下一步动作。
- `hover`: transform `translateY(-2px)`，180ms ease-out。
- `selected`: 蓝色边框＋青绿色 3px 底线；不使用大面积荧光。
- `loading`: 保留布局尺寸的骨架或按钮内 loading，不让页面跳动。
- `empty`: 明确原因和可执行动作，如“该范围暂无合法词表，去内容库导入”。
- `error`: 仅显示真实错误和恢复建议；接口未配置用“待接入”，不用红色报错。

## Motion

- 页面进入：内容整体淡入 180ms。
- 牌组切换：当前卡片 220ms 滑动＋轻微缩放，后卡保持可见。
- 词库列表搜索：150ms 淡入，不对每一行单独做跳动动画。
- 文章右侧面板切换：200ms `AnimatedSwitcher`，只改变透明度和横向 8px 位移。
- 遵守 `MediaQuery.disableAnimations`/reduced motion，关闭时保持最终状态。

## Dark Mode

深色主题将 `paper` 映射到 `#17242C`、`mist` 映射到 `#10191F`、`line` 映射到 `#33434C`；蓝绿渐变降低饱和度，正文保持至少可读对比度。文章正文使用略暖的深色纸面，避免纯黑背景长时间阅读。

## Design Principles

1. 选择范围和开始学习是两个动作，不能混成一个下拉框。
2. 四个学习方式完全独立；任何一项没有完成，都不能阻止另一项打开。
3. 空间用于内容，不用于装饰；文章和词库必须有可见的内容密度。
4. 本地优先，但来源、授权、模型和数据状态必须透明。
5. 一次只突出一个主要动作；收藏、读音、笔记和继续学习始终在可预期的位置。

## 页面层级实施记录（2026-09-17）

本轮按参考图完成学习工作区内部层级，不调整既有导航栏：学习首页只承载计划摘要和四个入口卡；词汇循环的叠层卡与词库列表是第二层，真正词卡是第三层；发音跟读和句子练习分别进入自己的配置/训练工作区；文章学习先进入入口页，再复用通用阅读器内核。文章入口页的四个快捷卡片均为独立回调，后续可分别接入计划、进度、收藏词汇和总结页面。

## 学习首页参考图锁定（v3.2，2026-09-17）

学习首页按批准预览图逐项锁定，不允许在此层自行增加内容：

1. 页头一行：左侧“学习”，右侧“坚持学习，遇见更好的自己。”。
2. 计划条一行三栏：待复习、今日计划、继续学习；不显示进度条、休息、退出或焦点任务说明。
3. 中间使用两条细分隔线包住“选择一个学习方向，开始今天的学习”。
4. 下方固定两列两行四卡，顺序为词汇循环、发音跟读、句子练习、文章学习。
5. 卡片只保留圆形图标、标题、参考图一句话说明、真实统计摘要和右侧箭头；不增加状态胶囊、进度条、尾部动作或教材入口。

这是学习首页的展示契约，不改变四个入口各自独立的任务计划、学习页面和本地状态。
