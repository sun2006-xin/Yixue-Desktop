# 模型目录持久化回归报告

日期：2026-09-12  
状态：PASS

## 根因

预览版目录按版本号生成。如果应用按 EXE 所在目录计算默认数据目录，升级后就会打开新的 SQLite
文件，模型扫描、翻译历史和学习记录会看起来消失。桌面启动器原本通过环境变量规避了这一点，
但直接双击版本目录内 EXE 仍可能复现。

## 修复与验证

- 预览版 EXE 默认把数据目录解析到发布根目录的 `user-data`。
- 用户显式设置的 `YIXUE_DATA_DIR` 仍拥有最高优先级。
- 新增跨版本 EXE 路径回归测试。
- 模型设置页面测试与持久化 Core 测试通过；本轮定向测试 13/13。
- 当前真实本地数据库仍只保存模型元数据和用途候选，不执行或加载扫描到的第三方模型。

## 状态边界

这解决的是数据目录漂移，不代表千问、GGUF 或其他通用模型已经具备译学专用运行内核。它们仍
需要经过能力声明、最小试跑、超时/取消和安全校验后，才能被允许承担对应任务。
