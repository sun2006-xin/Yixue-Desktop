## 已观察到的问题

### 完整性

- “It is getting warm in here.” 再次被整句遗漏，证明旧基准发现的漏译可以稳定复现。
- figures 被译为“数字”，reader 被译为“读者”，cloud sync 与 notes 被错误直译，说明上下文和词义选择不足。
- 中译英会把“校对”译成 school，把“听力部分”简化成 hearing part，信息虽未完全丢失但表达不可靠。

### 术语

- inference engine、loading、word-level timestamps、held-out evaluation set 等软件与模型术语不稳定。
- encryption in transit / data at rest 出现“过境内容 / 休息时的数据”的字面误译。
- 中译英的“指代关系、版面分析、留出评测集”均发生核心术语偏移。

### 论文表达

- association、confidence interval、generalizability 等学术词汇出现“社团、信心间隔、可概括性”等生硬或错误表达。
- 谨慎措辞基本能保留，但专业术语和目标语言自然度仍需人工盲评。

### 格式保留

- 16 条仅 5 条完整保留所有要求项。
- 失败类型包括空格折叠、大小写变化、路径插空格、时间冒号丢失、版本号改变、占位符被翻译、快捷键拼写变化和 Markdown 标记拆分。
- 这类错误不能只依赖模型微调；下一切片优先实现“翻译前占位保护、翻译后严格回填与校验”。

## 决策

1. v2 固定集冻结为评测用途，不进入训练集。
2. 当前结果作为未微调 OPUS-MT 基线，不填写虚构人工分数。
3. 先实现确定性的格式保护层并重新运行同一基线，目标是格式保留 16/16。
4. 再建立独立训练集处理漏译、术语和论文表达；候选模型输出后生成 A/B 盲评表。
