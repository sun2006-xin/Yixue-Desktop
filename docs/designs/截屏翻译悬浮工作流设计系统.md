# 截屏翻译悬浮工作流设计系统

版本：v0.1
日期：2026-10-06
状态：已确认
依据：译学现有《译学助手界面设计系统》v1.1、《译学品牌、启动动画与首页规格》v0.2，以及用户提供的有道截屏翻译参考图。参考图只用于提取交互规律，不随仓库分发。

## 设计目标

用户在其他 Windows 软件中看到不可复制的内容时，能用圆球或全局快捷键框选一次；截屏完成后马上回到原软件继续操作，同时让原文、译文和截取上下文留在一个可拖动的小窗中对照。

核心设计取舍：

- 截屏入口常驻，但足够轻，不与正在使用的软件争夺注意力。
- 选区反馈明确，支持取消和边缘调整。
- OCR 后自动开始翻译，减少一次确认操作；原文仍能修改并重新翻译。
- 对照窗非模态、可移动、默认置顶；主窗口负责查看历史和管理设置。
- 圆球、选区和结果窗沿用译学蓝绿品牌，不复刻参考图的红色工具栏。

## 组件规则

### 常驻圆球

- 默认尺寸 44×44 px，圆形热区不小于 44×44 px。
- 深海军蓝底，取景符号采用蓝—青绿—新生绿中的两色；图形保持高对比，不叠放多个标签。
- 空闲时静止，不做循环呼吸、粒子或持续发光；悬停显示“截屏翻译”提示。
- 单击启动选区；拖动可移动，释放后吸附到最近显示器边缘并保留安全边距。
- 右键菜单只提供“打开译学”“截屏翻译设置”“退出”。开关圆球在译学设置中完成，避免菜单同时出现重复开关。
- 圆球开启时关闭主窗口改为隐藏主窗口、保留后台服务；从圆球可重新打开主界面或退出进程。

### 选区覆盖层

- 覆盖当前屏幕并压暗背景；建议以深海军蓝 #032A52、42% 不透明度开始视觉验收，调整时保证后台仍能辨认。
- 选区内保持原始截图亮度，边框使用 #20C7B5、2 px；拖点为 8 px 白心圆点，使用蓝绿描边。
- 鼠标拖框选区；Esc 取消。松开鼠标即提交本次截图，不要求再点一次“开始翻译”。
- 屏幕底边不放全宽多功能工具条。提示“拖动框选 · Esc 取消”贴近选区显示，自动避开屏幕边缘。
- 不在第一版加入公式提取、摘要、润色等与截屏翻译无关的按钮。

### 悬浮对照框

- 初始尺寸 560×400 px，可调大小，最小尺寸建议 420×300 px；圆角 12 px，白色或当前主题工作面，边框 #DDE2E8，使用克制阴影。
- 默认出现在不覆盖选区的一侧，并保持在最前；用户可以拖动、收起、关闭或通过图钉切换置顶。
- 标题栏显示“截屏翻译”、当前处理状态和关闭/收起/置顶控制，标题栏可拖动窗口。
- 上部保留一张可展开的小幅截图预览，帮助确认 OCR 所属区域；第一版只在当前会话内存截图。
- 主体默认左右对照：左侧可编辑 OCR 原文，右侧可选择/复制译文；面板变窄时用“原文 / 译文”切换标签，避免挤压文字。
- 底部最多保留“复制译文”“重新截取”“查看历史”三个常用动作。复制原文作为原文卡片内的轻量图标操作。
- OCR 完成后自动开始翻译。用户修改原文后可点击“重新翻译”；每次成功翻译都写入本地翻译历史。

### 历史与设置

- 结果写入译学现有翻译历史，在记录上标出来源为“截屏翻译”。
- 历史默认仅持久化识别原文和译文，不保存截图图片；删除翻译历史时遵循现有隐私数据清理逻辑。
- 设置提供“启用悬浮圆球”和可录制的全局快捷键；快捷键冲突时说明原因并让用户改键，不静默失效。
- 圆球关闭时主窗口正常关闭即退出；圆球开启时关闭主窗口保留圆球。第一版不要求登录自启。

## 状态与动效

| 状态 | 表现 |
|---|---|
| 圆球空闲 | 静止、清晰可见；无持续动效 |
| 圆球悬停 | 显示短提示，轻微提升边框/阴影对比 |
| 选区 | 背景压暗、内容区清晰、八个拖点可见 |
| 识别中 | 对照框先显示截图预览和稳定骨架，不阻止其他应用接收输入 |
| 翻译中 | 原文可查看；状态文案明确显示“正在翻译”，不出现虚假进度百分比 |
| 翻译成功 | 原文/译文稳定显示；复制和重截按钮立即可用 |
| 未识别到文字 | 显示可理解的原因和“重新截取”，不留下空白结果 |
| 服务失败 | 保留截图预览和 OCR 原文，显示重试；服务来源按现有本地/远程状态规则展示 |
| 快捷键冲突 | 设置项显示冲突，保留用户可操作的改键入口 |

- 面板入场目标 120–180 ms 淡入，不做位移弹跳。
- 状态变化不能重排主要文本区域；按钮在加载时保留尺寸。
- 系统减少动效时取消缩放和渐移动画，只保留必要的状态变化。
- 屏幕坐标、圆球吸边和面板避让必须使用同一套多显示器/DPI 坐标规则。

## 设计边界

- 只把参考图用于“选区可见、动作易达、对照清楚”的交互灵感。
- 不复制其红色品牌色、长条动作栏、图标样式或多 AI 工具集合。
- 译学的差异化由常驻入口、不中断工作的对照框、既有翻译服务与统一历史构成。
- 截图处理边界遵守《译学发布、隐私与用户控制规格》：OCR 本地执行；远程翻译时只将识别出的文字发送到当前配置的 Provider，不上传截图图像。
