# 译学官方主题系统

## 目标

译学内置三套清晰、互斥的官方主题。主题负责颜色和装饰强度，动效等级继续独立设置；
用户自定义主题后续作为单独入口，不与官方预设混合。

## 1. 生机

- 定位：品牌默认主题，表达蓝天、知识流动与绿色成长。
- 主背景：`#F2F7FA`；内容表面：`#F9FBFC`。
- 侧栏：`#032F4B → #006270` 纵向渐变。
- 侧栏弧光：`#35E99A`，只出现在底部并保持低透明度。
- 选中项：`#1766E7 → #18C9A0`，允许轻微银白边缘与柔和绿光。
- 顶部：`#032F4B → #00586A`，与侧栏形成连续的深海蓝框架。
- 约束：弧光、蓝绿液态渐变和发光阴影只允许用于本主题。

## 2. 浅色

- 定位：论文、文献与长时间学习使用的低静模式。
- 主背景：`#F5F7F8`；内容表面：`#FBFCFD`。
- 侧栏：纯色 `#F1F4F6`；文字 `#253541`。
- 选中项：纯色 `#DDE8F2`，不使用绿色弧光、液态渐变或发光阴影。
- 顶部：纯色 `#F7F9FA`，边界 `#DCE3E8`。

## 3. 深色

- 定位：夜间、低光环境和视频字幕工作。
- 主背景：`#111519`；内容表面：`#181D22`。
- 侧栏：纯色 `#1B2026`；文字 `#E8EEF3`。
- 选中项：纯色 `#2A3641`，以明度区分，不使用彩色高光。
- 顶部：纯色 `#171C21`，边界 `#303840`。

## 组件规则

- 侧栏、窗口标题栏和页面标题栏必须来自同一套主题令牌，禁止写死蓝色。
- 浅色与深色主题强调内容，不使用品牌装饰弧光。
- 生机主题的装饰不得进入论文正文、输入框或长文本阅读区。
- 主题切换不得清空输入、切换当前页面或改变动效等级。
- 切换动画：完整 220ms、减少 90ms、关闭 0ms。
