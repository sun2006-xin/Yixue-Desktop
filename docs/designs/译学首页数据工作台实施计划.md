# 译学首页数据工作台实施计划

版本：v1.0  
日期：2026-09-15  
状态：执行中，作为 `P0.1` 首页增量的实施来源

关联规格：[`译学品牌与首页规格.md`](./译学品牌与首页规格.md)  
关联总计划：[`tasks/plan.md`](../../tasks/plan.md)

## 1. 目标

把首页从“静态展示卡片”建设为本地优先的学习与工作台。首页当前固定展示六个区域：

1. 继续任务
2. 今日学习
3. 翻译
4. 今日总结
5. 本周计划
6. 最近内容

六个区域都必须可交互，并能进入对应的独立工作区。首页只负责聚合和导航，翻译、
阅读、词典、学习和 AI 同传仍保持独立模块边界。

## 2. 当前事实与范围

### 已有基础

- Rust Core + SQLite 已有本地活动事件、翻译历史、词典、单词标注、翻译标注和文章来源接口。
- 阅读器已经保存文章、段落译文和阅读位置，可作为文章断点续做的基础。
- 首页已有首个静态切片：周目标、四项今日统计、快捷入口、最近活动和最近翻译继续入口。
- 预览版数据目录可放在用户选择的位置；新版预览包共用发布根目录旁的 `user-data`。
- 三套官方主题、动效等级和颜色主题容器已经存在；H6 已接入受控本地背景图、字体、独立状态栏颜色、实时预览和缺失资源回退。

### 本阶段明确不做

- 不在首页切片中启动或评测本地大模型。
- 不把首页改成完整学习系统；学习系统仍按 P4 独立开发。
- 不实现截屏翻译、AI 同传的完整业务流程，只接收它们未来写入的活动事件。
- 不接入服务器、云端账户或远程同步。
- 不把计划目标当成实际完成量，不用演示数据冒充真实数据。

## 3. 五类本地数据契约

所有数据写入用户选择的本地资料库，日期以本机时区的 `yyyy-MM-dd` 为准。SQLite 是
跨模块业务数据的事实来源，页面本地状态只做临时编辑和缓存。

### 3.1 ActivityEvent：实际活动事件

用于记录已经发生的事情，不记录“打算做什么”。首轮支持：

- 翻译：完成一次翻译请求，保存来源模块、语言方向和可统计的词数/字符数。
- 阅读：实际推进的页数或段落数，保存文章来源 ID。
- 词汇：用户明确加入学习、标记掌握或完成复习的单词数。
- 练习：完成的练习数量。
- 口语/同传：实际运行的语音学习或同传时长。
- 专注：主动专注时长和类别，例如学习、阅读、翻译或工作。

事件要求：稳定 ID、发生时间、模块类型、标题、可选来源 ID、时长、数量和可选详情。
重复写入同一 ID 必须幂等；暂停时间、空输入、只打开页面不能算作完成活动。

### 3.2 DailyPlan：每日计划

按日期保存：

- 当日标题和任务列表；
- 每项任务的类型、目标、开始时间、预计时长、完成状态和关联模块；
- 自由书写的计划、心得、注意点；
- 可暂停、顺延、拆分和重新安排，不用惩罚性红色表示未完成。

旧版只有全局词数、页数、分钟数和星期选择，必须通过版本迁移转换为默认的每日计划，
不能丢失用户已经填写的目标。

### 3.3 ResumeTask：继续任务

记录用户最近未完成的工作：

- 任务类型和标题；
- 关联文章/翻译/学习项目/同传记录 ID；
- 当前页、段落或步骤；
- 完成比例和最后操作时间；
- 可恢复的目标页面和主按钮文字。

阅读器优先复用已有文章来源的 `readingPosition` 与段落译文；应用关闭后重新打开，
首页必须能恢复到上次位置。最近一次普通短句翻译不能伪装成“未完成文章任务”。

### 3.4 Reminder：本地提醒

保存任务提醒、开始时间、重复规则、专注结束/休息规则、启用状态和处理状态。

首版范围：软件运行或最小化时可靠显示应用内提醒、专注结束提醒和休息提示；应用完全
退出后的 Windows 系统通知另设安装器与系统通知切片，不用普通计时器冒充已经支持。
所有提醒均由用户主动开启，默认不创建后台自启动任务。

### 3.5 UserProfile：本地用户资料

首轮只保存可选昵称和首页自定义鼓励语。昵称用于显示“早上好，花鱼鱼”这类问候，
不上传网络，也不参与模型训练。完整个人中心、头像和账户体系留到后续阶段。

## 4. 六个区域的交互标准

### 4.1 继续任务

- 卡片展示最近未完成任务、来源模块、当前位置、进度和最后操作时间。
- 主按钮统一为“继续”，直接恢复对应工作区。
- 支持继续文章翻译、继续阅读、继续词汇任务和继续同传记录。
- 没有未完成任务时显示“今天，想从哪里开始？”并提供翻译、阅读、学习、专注入口。

### 4.2 今日学习

- 展示今日计划完成度、预计剩余时间和主要任务。
- 点击进入“今日计划”独立工作区，可编辑任务、自由笔记、心得和注意点。
- 计划完成由实际活动事件更新，不允许仅点击“完成”就伪造学习统计；纯计划任务可以
  记录为计划状态，但今日总结必须区分“计划完成”和“实际活动”。

### 4.3 翻译

- 点击进入快速翻译，不复制快速翻译内部状态。
- 首页只提供快速输入和最近翻译入口。
- 翻译完成后由快速翻译模块写入历史和活动事件，首页只读取摘要。

### 4.4 今日总结

必须显示真实数据；尚未接入的模块显示“暂未接入”，不显示误导性的 0。首轮指标：

- 翻译次数、处理词数/字符数；
- 实际学习词汇数和复习数；
- 阅读文章数、页数/段落数；
- 收藏句子数、收藏单词数；
- AI 同传/语音学习时长；
- 专注学习时长、专注次数、休息次数；
- 与昨日或近七日基线的变化。

点击进入今日统计详情，可按模块查看事件明细；统计逻辑集中在 Core/聚合服务，不在
每张首页卡片中各写一套计算规则。

### 4.5 本周计划

- 首页当前以“计划日历”显示本月完整 42 格月历，同时保留已安排天数和今日计划摘要；原有“本周”概念保留在计划统计与详细计划页中。
- 点击进入真实月历工作区；月历可切换月份，选择某日查看和编辑当天计划。
- 日详情同时展示计划、实际活动、完成状态、提醒和心得。
- 支持“今天”和“明天”快速添加计划；目标支持词汇、阅读、口语、写作、专注和自定义项目。

### 4.6 最近内容

- 时间线显示文章、快速翻译、截屏翻译、同传记录、收藏词和学习项目。
- 每项显示类型、标题、最后位置/状态、时间和本地保存状态。
- 点击打开对应详情或继续任务；卡片总入口“查看全部历史”进入独立历史工作区。
- 支持搜索、固定和按类型筛选；删除前必须二次确认并说明影响范围。

## 5. 统计口径

| 指标 | 计入条件 | 不计入 |
|---|---|---|
| 翻译次数 | 翻译请求成功并完成本地记录 | 空输入、失败、取消、仅打开页面 |
| 翻译词数 | 可识别词数；无法可靠分词时显示字符数 | 把字符数冒充词数 |
| 学习词汇 | 明确加入学习、掌握或完成复习 | 普通查词、只看释义 |
| 阅读量 | 实际推进的页数/段落数 | 只打开文章 |
| 文章数 | 当天实际推进过的独立文章数 | 重复刷新同一文章 |
| 收藏句子 | 用户明确收藏的句子/翻译标注 | 普通翻译历史 |
| 专注时长 | 活动状态下的累计秒数 | 暂停、休息、应用关闭期间 |
| 同传/视频时长 | 实际运行并记录的会话时长 | 尚未接入模块的空值 |

## 6. 动态问候与休息提示

- 05:00–11:00：早上好
- 11:00–13:00：中午好
- 13:00–18:00：下午好
- 18:00–05:00：晚上好
- 昵称存在时追加昵称；自定义鼓励语只在首页辅助位置展示。
- 专注达到用户设置的提醒阈值后显示“辛苦了，休息一会”，不每秒刷新问候，也不覆盖正在
  进行的核心操作。

## 7. 专注模式默认值

提供三种预设：`25 分钟 + 5 分钟休息`、`50 分钟 + 10 分钟休息`、自定义。默认采用
`50 + 10`，用户可随时修改；每四个周期可选择长休息。暂停、继续、提前结束和应用关闭
都要保存状态，下一次打开时由用户选择恢复、结束并计入已完成部分，或放弃本次记录。

## 8. 主题与本地资料库

主题扩展分为两步：

1. 首页功能切片先只依赖现有生机/浅色/深色和动效等级，保证工作面清晰。
2. 功能稳定后扩展安全的自定义主题编辑器：本地壁纸、内置/允许列表字体、背景模式、
   顶部栏颜色、侧边栏颜色、选中状态和可读性遮罩，并提供实时预览、应用、恢复默认。

用户壁纸应复制或受控引用到资料库，文件缺失时回退；字体不可导致启动失败。主题不得
   通过远程地址自动拉取资源。

6. 每完成一个可交付切片就更新 PR 和进度文档；不把半成品或失败构建上传为最新版；
7. 重新构建成功后更新桌面快捷方式所指向的“最新预览版”并做无命令行启动检查。

GitHub 上传只包含源码、文档和明确允许发布的构建清单，不上传用户数据库、密钥、模型
缓存、个人壁纸或本地词典数据。

## 11. 完成标准

首页达到以下条件才算本阶段交付：

- 六个区域都能点击并进入对应工作区或核心模块；
