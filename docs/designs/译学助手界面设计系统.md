# 译学界面设计系统

版本：v1.1
基线：用户于 2026-09-08 确认的快速翻译界面图

## 设计原则

- 专业桌面工具，不做聊天机器人外观。
- 高信息密度，但通过边框、分区和留白保持清晰。
- 主任务始终位于中间；解释、例句、收藏和历史位于右侧。
- 本地/远程状态通过页头状态胶囊随时可见；低频详情进入设置页。
- 五大核心页面共用导航、浮层页头和交互语言，不再常驻底部状态栏。
- 品牌愿景语为“让世界，可以理解。”，用于启动页和展开侧边栏；产品行动语为
  “译懂世界，学会表达。”，用于首页。两句不在同一视觉层级并排出现。
- 首页承担继续任务和快速开始，不做宣传页或五张同构功能卡片。

## 颜色

- 品牌标志：天空蓝 `#35A7FF` → 青绿 `#20C7B5` → 新生绿 `#45D46A`；
  钢笔使用高光亮银和墨黑细节。

- 侧栏顶部/主体：`#03274A` 至 `#002C55` 的深海军蓝；实现时默认纯色
  `#032A52`，避免持续渐变重绘。
- 选中导航：`#1763D6`。
- 主按钮：`#155FD1`；悬停渐变 `#1677FF → #11B8C8`；按下 `#0A49AC`。
- 导航悬停：`#0B3E70 → #0E568C`；选中 `#1763D6 → #1388D8`。
- 主背景：`#F5F7FA`。
- 工作面：`#FFFFFF`。
- 边框：`#DDE2E8`。
- 主文字：`#161A20`。
- 次文字：`#67707C`。
- 链接/术语强调：`#0D5ECC`。
- 本地安全状态：`#16A765`。
- 警告：`#D97706`；错误：`#D13C3C`。

## 字体

- Windows 中文：优先 Microsoft YaHei UI。
- 英文与数字：优先 Segoe UI。
- 页面标题：30–34px，700–800。
- 导航文字：16–18px，500；选中 600。
- 正文输入：17–19px，行高 1.65。
- 卡片标题：16px，600。
- 辅助信息：12–14px。

## 间距与布局

- 桌面侧栏：224px；窄屏改为底部导航或折叠抽屉。
- 页面外边距：桌面 36px；中等窗口 24px；窄屏 16px。
- 主区与右栏间距：16px。
- 右侧学习栏：320–352px，可折叠。
- 基础间距单位：4px；常用间距为 8、12、16、24、32px。
- 主工作卡圆角：10px；浮层页头：12px；普通按钮：7px。仅状态和筛选器可用胶囊形。

## 核心组件

- 导航项：56px 高，左图标、右文字；选中后蓝底白字。
- 翻译编辑器：原文和译文等宽双栏，中间 1px 分隔线。
- 页头：64px 浮层卡片，标题在左；处理状态、语言方向、设置在右。
- 学习卡：标题栏可折叠，正文容纳术语、例句、收藏词和历史。
- 底部操作条：翻译、清空、粘贴、自动换行；快捷键显示在按钮内部。
- 服务状态胶囊：页头显示实际处理路由和当前 Provider（本地优先、随包模型、本地模型或自定义接口）；点击进入模型与服务。
- 版本、数据目录、隐私和更新状态：集中放入设置页，不占用主任务空间。

## 状态

- Hover：160ms 渐变、阴影抬升 2px；文字和图标保持稳定位置。
- Active：缩放至 0.975，持续 90ms，并降低阴影。
- Loading：按钮保留宽度，显示进度，不让布局跳动。
- Empty：解释下一步操作，不只显示空白。
- Error：就地说明原因和恢复办法，不暴露密钥、路径或原始异常。
- Disabled：降低对比度但保持可读，并提供禁用原因。

## 动效

- 页面切换：先显示 180ms 骨架屏，再以 220ms 轻微横向位移加淡入。
- 侧栏选中块：160ms。
- 卡片展开：180ms。
- 翻译结果：分段渐显，不使用打字机效果拖慢阅读。
- 骨架屏仅使用一次有限的明暗扫过，不无限循环，不阻塞页面稳定状态。
- 支持“减少动效”；开启后取消位移和缩放，只保留极短淡入。
- 侧边栏支持固定展开、完全收起和左缘临时唤出；完全收起时不保留图标栏，
  临时唤出使用覆盖层避免正文反复重排。
- 导航选中状态由唯一的“地平线玻璃”在各项之间移动：上蓝下绿、银白折射线，
  点击仅单次轻回弹，不持续跳动。

## 五大页面

1. 快速翻译：双栏编辑器和右侧学习卡。
2. 截屏翻译：选区管理、悬浮取景框和历史。
3. 阅读器：原版论文、译文对照、批注、标签、概要和导出。
4. 学习：词汇、听说读写、默写、句子判断、每日计划。
5. AI 同传：字幕、系统音频/麦克风、可选录制、时间轴和总结。

## 自定义主题

主题只能覆盖设计令牌、字体声明和安全图片资源，不改变导航信息架构，
不执行脚本。用户自定义主题必须保留文字对比度、焦点状态和隐私状态可见性。
