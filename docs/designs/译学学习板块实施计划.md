# 译学学习板块实施计划

版本：v1.0  
日期：2026-09-16  
状态：L1-L6 预览闭环已实现；教材内容采用自写、开放许可或用户合法导入

关联规格：[`译学首页数据工作台实施计划.md`](./译学首页数据工作台实施计划.md)  
关联数据基础：快速翻译词典卡、收藏词库、翻译历史、每日计划和本地活动事件

## 1. 产品定位

学习板块不是单纯的“显示收藏单词”页面，而是面向不同学习阶段的本地学习工作台：

- 小学、初中、高中：按学段、年级、教材单元组织词汇和课文；
- 四级、六级、考研、考博：按考试阶段、词汇层级和学术场景组织学习；
- 社会学习者：按日常、工作、专业领域和发音目标组织学习；
- 所有人：可从翻译、阅读、词典和文章中把真实遇到的内容加入学习。

教材和考试内容必须使用自写、公开许可、用户合法提供或后续取得授权的资料。计划中的词汇数量是学习目标，不代表可以直接复制任何受版权保护的词表或课本全文。

## 2. 核心数据原则

词典保存“这个词是什么”；学习记录保存“用户学到什么程度”。两者分开，避免词典更新覆盖用户数据。

首批拟新增的学习层数据：

- `learning_sets`：学习集合，例如小学五年级、六级、考研核心、我的工作词汇；
- `learning_items`：某个词条在某个学习集合中的状态、目标语言、下次复习时间和掌握阶段；
- `learning_reviews`：每次复习的结果、题型、耗时和发生时间；
- `study_sessions`：一次学习会话的开始、暂停、结束、完成量和来源。

数据默认保存到用户选择的本地资料库，不设人为总条数上限；分页和单次渲染上限只用于保护界面性能，容量策略由用户决定。

## 3. 首个可交付切片：词汇循环复习

先完成一条完整链路，再扩展其他学习形式：

`收藏/加入学习 → 选择学习集合 → 今日队列 → 词卡学习 → 复习测试 → 保存结果 → 首页统计`

每个词卡至少展示：

- 单词、音标和英美发音入口；
- 词性、分层义项、词形变化和词族关系；
- 双语例句、例句朗读和必要的搭配；
- 用户笔记、来源、所属学习集合和当前掌握阶段。

学习流程支持以下题型：

1. 看词认义：先给单词、读音和例句，用户确认是否掌握；
2. 英译中：给英文，回忆中文义项；
3. 中译英：给中文，回忆英文词形；
4. 词形/变种辨认：识别过去式、过去分词、名词、形容词等关系；
5. 标记“不会、模糊、掌握”，不会的词回到更近的复习队列。

初版使用可解释的固定复习间隔，先保证可追溯和可修改；后续再根据真实数据增加自适应间隔，不把模型输出当成复习事实。

## 4. 学习主页结构

- 顶部：当前学习集合、今日目标、待复习数量、已完成数量；
- 左侧：今日复习、待学习、已收藏、全部词汇、学习集合和搜索筛选；
- 中央：一张词卡或一道复习题，支持读音、例句、释义和标记结果；
- 右侧：本词详情、我的笔记、来源、相关翻译历史和学习进度；
- 底部：继续学习、加入今日计划、暂停会话和结束并保存。

快速翻译右侧“加入学习”、收藏词库、翻译历史和后续阅读器选词，都进入同一个学习数据接口，不各自维护一套学习状态。

## 5. 后续学习轨道

### L2 学段与考试词书（已实现）

学习集合通过词典来源、学段、考试阶段、单元和难度筛选。当前页面已提供全部词汇、基础、小学、初中、高中、四级、六级、考研/学术、考博与社会/工作、我的收藏目录；集合词数从本地词典覆盖标签实时计算，缺少合法教材数据时显示“待补充”，不伪造官方覆盖证明。选中集合后才按需建立对应学习项，避免一次性复制所有词书状态。

### L3 发音训练（已实现本地预览闭环）

独立发音跟读轨道支持播放单词和例句、跟读计时、重复练习和“需要再练/还不确定/读得清楚”自评。本轮另接入 Windows 系统语音识别预览：只对当前单词做词级文本比对并保存分数，不保存原始录音、不上传项目服务器，也不冒充音素、重音或语调评分。`speech_to_text` 的 Windows 支持仍属于 beta，音素/重音/语调分析继续保留为后续独立语音接口。

### L4 句子拼写与表达（已实现本地预览闭环）

从当前词典双语例句生成句子练习，支持中译英、英译中、手动输入、英文词块辅助、标准答案、错误位置提示和下一句；每次作答保存题型、答案、正确性和错误信息，后续可扩展用户收藏句与合法题库。

### L5 文章与短报学习（已实现本地预览闭环）

学习页提供三篇自写离线短文，支持按段阅读、显示/隐藏译文、播放原文、标记已读、断点恢复、收藏段落、把文章词条加入当前词书和打开现有文章阅读器。文章进度、收藏段落和查词词条写入本地学习数据。用户本地文件与更丰富的合法文章继续由阅读器承载。

### L5.5 教材与课程包（已实现预览闭环）

教材轨道提供小学、初中、高中、四六级、考研考博和社会/职场等适用范围目录；目录只表达产品支持的学习范围，不把某个出版社版本冒充为内置内容。预览版内置三篇译学自写课程，并支持用户导入自己自写、开放许可或已取得合法使用权的教材：

- 标准包为 UTF-8 JSON，或 ZIP/`.yxtbook` 内的 `learning-textbook.json` 清单；每个课次包含原文，可选译文和词汇；
- 普通 TXT、Markdown、DOCX 和可提取文本的 PDF 由导入对话框补充年龄段、学段、版本、许可证/授权说明、权利人和来源；
- 课程包保存到用户选择的本地资料库 `learning-textbooks.json`，课次学习进度复用 `article_progress`，词汇加入现有学习集合；
- 设置中的本地数据管理可以单独导出或删除“教材与课程包”，不会把课程资料藏在模型缓存或安装目录里；
- 导入器限制文件大小、课次数量、清单大小、URL 协议和字段长度，不执行教材文件中的代码，也不自动联网下载或把用户教材上传；
- “网上能看到”不等于“可以复制或再分发”。商业教材不随软件发布，开放许可也必须保留来源、许可证和署名信息。

### L6 AI 总结与个性化练习

AI 只在用户主动选择理解与总结模型后用于文章总结。当前文章学习页已接入 OpenAI 兼容本地/API Provider 的统一回调；没有模型时明确提示“接口已预留”，词典、复习、发音播放、句子练习、教材阅读和历史记录仍然可用。错题解释、例句扩展和更完整的学习反馈继续复用该接口，但不阻塞本地学习闭环；本轮不启动本地模型推理，也不把普通翻译模型当成发音评分器。

## 6. 质量和隐私边界

- 只有已发布、来源和字段完整的词条才能进入官方自动学习队列；候选词条明确标注状态；
- 学习统计只由真实复习、练习和会话事件产生，打开页面不计入学习量；
- 用户笔记、错误记录、学习进度和文章来源全部保存在本地；
- 用户可以按学习记录、词典、历史和文章类别查看、导出或删除；
- 词典扩建不得覆盖收藏、笔记、复习状态或历史记录。

## 7. 实施顺序与验收

1. ✅ L1：学习集合、学习项、复习记录和收藏/历史接入；
2. ✅ L1：词卡、四类基础题型、掌握标记、继续学习和会话恢复；
3. ✅ L1：真实复习事件回写首页今日总结和今日学习；
4. ✅ L2：学段/考试词书筛选与教材课程包导入、课次学习和本地进度；
5. ✅ L3：发音训练的本地播放、跟读计时、自评、Windows 词级识别评分和记录；
6. ✅ L4：句子拼写/翻译训练、错误提示和作答记录；
7. ✅ L5：自写文章学习、段落进度、收藏、生词入词书和阅读器入口；
8. ✅ L6：文章 AI 总结的可选 Provider 接入和无模型降级提示；高阶模型质量、音素级 ASR 评分另行验收。

L1 验收要求：关闭软件后重新打开仍能恢复学习队列；每次复习结果可追溯；英译中、中译英和不会重排均有效；收藏、笔记、例句朗读和历史恢复不依赖模型；首页统计与学习记录一致。

## 8. L1-L5 已落地内容

本轮已将学习页从原来的专注计时占位页替换为独立的多轨道学习工作区：

- `lib/core/learning_workbench.dart`：版本化学习集合、学习项、复习记录、会话和本地文件 store；
- `lib/core/learning_tracks.dart`：学习集合目录、词典标签筛选和句子答案标准化；
- `lib/core/learning_articles.dart`：自写离线文章种子和段落双语内容；
- `lib/core/learning_textbook_catalog.dart`：教材包 schema、JSON/ZIP/文档导入、适用范围目录和本地教材 store；
- `lib/features/learning/learning_workspace.dart`：词汇循环、学习集合、发音跟读、句子练习、文章学习、教材导入和 AI 总结接口；
- `lib/features/learning/learning_textbook_workspace.dart`：教材范围、课程包、课次原文/译文和词汇学习操作；
- 真实程序写入用户选择的资料库 `learning-workspace.json`，没有选择资料库的组件测试只使用内存 store；
- 教材包写入同一资料库下的 `learning-textbooks.json`，不把用户教材复制到安装包；
- 每次复习都会产生一条可追溯记录，并向首页活动统计写入一个 vocabulary 事件；
- 词典新增条目采用增量入库，不覆盖既有复习进度、收藏或笔记；
- `不会` 当天返回，`模糊`采用短间隔，`掌握`按 1/2/4/7/14/30/60/90 天逐步拉长；
- 学习模块不调用模型。翻译质量、AI 总结、发音评分和自适应算法仍由后续模型/学习切片负责。

本轮新增的学习记录包括：

- `learning_sets` 的学段、语言、单元、标签和系统集合标记；
- `pronunciation_practices` 的本地跟读时长和自评结果；
- `sentence_attempts` 的题型、输入答案、标准答案、正确性和错误位置；
- `article_progress` 的文章断点、已读段落、收藏段落和查词词条。
- 教材课次以 `textbook:<package_id>:<lesson_id>` 作为 `article_progress.article_id`，保持学习接口统一；
- Windows 词级跟读结果写入既有 `pronunciation_practices`，只保存识别文本与分数，不保存录音。

所有新字段都允许旧 v1 文件按默认值迁移到 v2；学习条目和练习记录仍不设人为总量上限，单次渲染和文件解析上限只用于保护客户端。

本轮验收覆盖核心状态、v1 数据迁移、队列恢复、复习安排、词卡释义、集合切换、发音自评、词级麦克风评分、句子作答、文章断点/收藏、教材包解析、教材库持久化、教材页面交互和页面重载；完整音素级发音评分、用户未授权的商业教材、在线自动抓取教材和完整考试词书覆盖仍不属于已完成承诺。
