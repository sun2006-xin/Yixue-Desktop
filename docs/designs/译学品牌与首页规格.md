# 译学品牌、启动动画与首页规格

版本：v0.2
日期：2026-09-09
状态：品牌、启动动画、侧栏交互、首页静态切片、统一活动摘要、快速翻译历史与首个继续任务已实现；
首页数据工作台按 [`译学首页数据工作台实施计划.md`](./译学首页数据工作台实施计划.md) 分 H0–H6 接入

## 1. 品牌核心

- 产品名：`译学`
- 品牌愿景语：`让世界，可以理解`
- 产品行动语：`译懂世界，学会表达。`
- 品牌含义：翻译帮助用户读懂信息，学习帮助用户形成自己的表达能力。
- 品牌气质：清朗、亲和、可靠、有生命力；不冰冷，不低龄，不做常见 AI 工具外观。

### 使用层级

- 启动页：标志书写完成后显示品牌愿景语 `让世界，可以理解`
- 首页：使用产品行动语 `译懂世界，学会表达。`
- 首页辅助引导：`从看懂，到说出；从翻译，到真正掌握。`
- 空状态引导：`今天，想从哪里开始？`
- 隐私说明：`内容默认留在本地，学习进度只属于你。`

两句标语属于同一品牌，但不能在同一视觉层级并排出现。启动页讲愿景，首页讲用户
得到的能力；辅助文案只在对应场景出现，不能与当前页面主标语争夺视觉中心。

## 2. 标志方向

采用已确认的 02 号流动分块造型，并以 01“晴空新芽”作为主配色基础：

- 左侧圆润块：天空蓝，代表语言、沟通与更大的世界。
- 中间书写轨迹：蓝绿渐变，代表跨越两种语言的连接过程。
- 右侧圆润块：新生绿，代表学习、成长和长期积累。
- 下方笔尖：高光亮银，使用墨黑笔缝与透气孔强化钢笔辨识度。
- 白云感：仅由块间留白和高光表达，不使用独立白色组件。

V3 透明主稿是当前唯一彩色生产源；界面、启动动画和 Windows 图标不得各自重画，避免再次出现比例、光泽和钢笔结构不一致。

## 3. 启动动画

### 分镜

1. `0–220ms`：深海蓝绿整窗背景显现，不套软件白框或卡片。
2. `220–2350ms`：标志沿书写方向缓慢显现，蓝、青绿、新生绿和亮银笔尖依次完整可辨。
3. `2350–2920ms`：`译学`与品牌愿景语“让世界，可以理解”依次淡入。
4. `2920–5200ms`：完整品牌定格约两秒，只保留一次克制的银色扫光。
5. `5200–5600ms`：整体淡出并进入工作区，避免黑屏或突变。

### 运行规则

- 动画与应用初始化并行，不把动画当作额外等待时间。
- 首次冷启动固定完整展示约 `5.6s`，保证用户能看清书写过程并看到约两秒最终 Logo。
- 初始化超过动画时长时，只保留极轻的高光呼吸，并显示真实加载状态。
- 二次启动使用约 `3.6s` 简版；设置中允许关闭启动动画。
- 系统开启“减少动效”时，使用静态标志加 `250ms` 淡入。
- 禁止声音、粒子爆炸、无限循环和虚假百分比。

## 4. 侧边栏品牌区

- 名称由“译学助手”统一改为“译学”。
- 展开状态显示：标志和 `译学`。空间充足时可在名称下显示小号品牌愿景语
  `让世界，可以理解`；窗口变窄或侧栏收起时自动隐藏。
- 侧边栏不同时放置两句标语。标语使用低对比度雾白色，只做品牌陪衬；导航仍是主要信息。
- 收起状态不保留标志或图标列，只在左缘显示 20px 蓝绿唤出把手；悬停或点击后显示完整侧栏。
- 标志仅在首次进入时做一次 `280ms` 高光掠过；日常不持续闪烁。

### 展开、收起与临时唤出

- 固定展开：侧边栏宽 `244px`，占据布局空间，适合频繁切换功能；品牌标志显示区为 `54×54px`。
- 完全收起：不保留图标栏，工作区取得全部宽度；左侧边缘仅保留一个
  `20–28px` 的半透明唤出把手。
- 临时唤出：悬停或点击左缘把手后，侧边栏以浮层方式覆盖工作区，不推动正文，
  并提供固定按钮切换为展开状态。
- 收起动画目标 `200ms`，临时唤出目标 `220ms`；动效期间保持内容可操作，
  系统开启减少动效时改为极短淡入淡出。
- 支持键盘切换，默认快捷键在实现阶段结合编辑器冲突测试后确定，并允许用户修改。
- 使用用户数据目录中的版本化 JSON 记住固定/收起选择；缺失或损坏时安全回退为展开。全屏阅读、字幕和专注学习自动收起作为后续增量。

### 地平线玻璃选中项

- 当前项使用唯一一块可移动的选中玻璃，不让每个导航按钮同时发光。
- 玻璃上方约 `65%` 为天空蓝，下方约 `35%` 为新生绿，中间使用细窄银白折射线。
- 切换页面时，玻璃沿导航纵向移动到目标项；悬停上浮 `2px`，点击先缩至
  `0.975`，再单次回弹至 `1.015` 后稳定。
- 点击时绿色地平线最多上升 `3px`，表达持续成长；不得使用循环弹跳、粒子或强霓虹。
- 真实背景模糊只用于当前选中玻璃和临时浮层边缘，其他区域使用静态渐变与半透明色，
  避免整条侧栏持续重绘。

## 5. 首页定位

首页是“继续工作与开始新任务”的日常工作台，不重复侧边栏，不做宣传落地页。

### 桌面布局

#### A. 品牌与继续区

- 左上显示时间问候、产品行动语“译懂世界，学会表达。”和本地隐私状态。
- 最大视觉区域承担“继续任务”，展示最近一次未完成内容，例如继续阅读第 12 页、继续今日单词或继续会议记录。
- 只有一个明确主按钮：`继续`。

#### B. 万能开始入口

同一入口支持：

- 输入或粘贴文字，进入快速翻译。
- 拖入 PDF、Word 或纯文本，进入阅读器。
- 点击截屏或显示快捷键，进入截屏翻译。
- 开启系统声音或麦克风，进入 AI 同传。

入口根据内容类型给出下一步，不自动上传任何内容。

#### C. 今日学习

- 显示今日目标、已完成数量、预计剩余时间和一个主动作。
- 支持继续背词、默写、听写、造句或中英互译。
- 不按“小学生/大学生/社会人士”固定分类，而按目标、水平、内容与时间组合。

#### D. 最近内容

- 使用紧凑时间线展示最近文章、翻译、截屏、字幕记录和学习收藏。
- 每项显示内容类型、最后位置、时间和本地保存状态。
- 支持搜索、固定和清除；删除必须二次确认并说明影响范围。

#### E. 日历与目标计划

- 首页显示月历或周历，可查看每日学习安排、完成状态和连续学习情况。
- 目标支持词汇数量、阅读时长/篇幅、口语时长、写作次数和自定义目标。
- 计划允许暂停、顺延和重新分配，不用惩罚性红色制造打卡压力。
- 点击某日可查看当天计划、学习事件和总结，并能跳转到对应核心功能。

#### F. 今日总结

- 汇总今日学习分钟数、阅读页数/字数、学习词汇、口语时长、完成练习和收藏内容。
- 展示与昨日或近七日基线的变化，但不使用夸张排名或虚假激励。
- 数据来自各核心模块写入的统一活动事件；首页只聚合，不复制模块业务逻辑。
- 用户可关闭某类统计、清除记录或导出学习报告；所有数据默认保存在本地。

### 模块边界

- 首页通过统一的活动事件、计划接口和最近任务接口读取摘要，不直接依赖某个页面内部状态。
- 快速翻译、截屏翻译、阅读器、学习和 AI 同传保持独立路由、状态与服务边界。
- 每个核心模块可以单独升级、停用或迁移；只要保持共享接口兼容，首页和其他模块不受影响。
- 跨模块共享内容只使用稳定对象：内容来源、任务、活动事件、学习项目和本地文件引用。

### 视觉与动效

- 首页使用纸白工作面、天空蓝到新生绿的局部轨迹，不铺满大面积渐变。
- 允许品牌轨迹跨越区域边界，形成可记忆的非对称构图。
- 鼠标经过入口时，轨迹向目标方向推进 `4–8px`；点击后缩放至 `0.975` 再进入页面。
- 页面加载采用已有骨架屏语言，但骨架形状必须对应首页真实结构。
- 所有动效支持减少动效，且不得阻塞点击。

### 三套官方主题与动效等级

外观设置保持直接明确：

1. `生机`：地平线玻璃、蓝绿环境光与液态选中项，适合首页和日常学习。
2. `浅色`：纸白/中性工作面、低阴影、无装饰弧光，适合论文和长时间工作。
3. `深色`：克制深灰表面、无彩色发光，适合夜间和视频字幕场景。
4. 动效等级：完整、减少、关闭；独立于三套主题。

默认使用“生机＋完整动效”；阅读器进入专注阅读时可临时切换为浅色或深色并隐藏侧栏。
用户可设置全局默认值，也可让单个页面暂时覆盖；退出页面后是否保留覆盖由用户选择。

## 6. 成功标准

- 用户打开应用后 3 秒内能找到“继续上次任务”或四种新任务入口。
- 首页不出现五张同构的大功能卡片。
- 品牌名和标志颜色在启动页、侧边栏和首页保持一致；愿景语与行动语按场景固定使用。
- 1280×720、1440×900 和窄窗口下无溢出；主要按钮保持可见。
- 启动动画与初始化并行，关闭动画和减少动效均可正常进入应用。
- 标志在 16、32、48、256 像素下仍能识别轮廓和钢笔特征。
