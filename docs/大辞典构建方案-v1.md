# 译学助手大辞典构建方案 v1

版本：v1
日期：2026-09-14
状态：内部 v2 基础结构已落地，等待分批制作和人工复核数据

## 1. 先说结论

译学助手的大辞典采用“两条数据路线”，不能把所有来源混成一个没有出处的数据库：

1. **译学公开词典包**：由项目自写内容和完成许可审查的开放数据组成，可以随预览版或正式版发布。
2. **用户个人词典包**：用户自己制作、合法取得或明确获授权的内容，只保存在用户选择的本地目录；除非授权明确允许，不进入 Git、EXE、公开下载包或项目训练集。

你拥有牛津词典，可以把它作为个人查阅、人工核对和学习参考。但“拥有一本书或一个订阅账号”不等于获得复制、重新整理、公开分发或用于训练的权利。牛津学习词典官方条款把产品内容及相关知识产权归于 OUP，并限制系统性复制、向非授权用户分发或让非授权用户访问。因此本项目不抓取、不批量抄录、不把牛津释义和例句直接写进公开词库；若要把牛津内容导入软件，必须先确认你购买的具体产品条款明确允许该用途。

本方案是工程合规方案，不是法律意见。公开发布前，对具体数据包进行一次著作权和开源许可证复核。

## 2. 我们要做的“大”是什么

第一目标不是堆出几百万个未经审核的词条，而是做一个能支撑快速翻译、文章阅读和学习训练的高质量词库：

- 英汉双向检索；
- 单词、词形变化、常用短语和固定搭配；
- 音标、英美发音标记、词性和多义项；
- 自写的自然中文释义；
- 自写或许可明确的双语例句；
- 日常、学习、工作、学术等场景标签；
- 同义词、反义词、词族和搭配关系；
- 来源、许可证、版本、修改记录和质量状态可追溯；
- 能被学习模块用于收藏、笔记、默写、错题和间隔复习。

先做“高频且真正能用”的 500 条质量切片，再扩展到 3,000—5,000 个高频词和短语；质量闸门稳定后，再按考试、学术、职业和其他语言逐包扩展。数字是阶段目标，不代表当前已经拥有这些数据。

## 4. 词条数据结构

当前软件的词典包 v1 需要 `word`、`ipa`、`part_of_speech`、`meanings`、`example` 和 `example_translation` 六类字段。它先继续用于小型用户词典包和界面联调。

大辞典生产数据增加可追溯字段，建议采用 v2 内部结构，再导出为当前应用可读取的 v1 兼容包：

```text
entry_id                 稳定词条 ID，不用中文释义作 ID
language_pair            例如 en-zh
lemma                    原形
variants                 词形变化、英美拼写和常见变体
ipa                      英音/美音及发音来源
part_of_speech           词性
senses                   多义项，每项独立保存中文释义、用法和领域
collocations             常见搭配与固定短语
examples                 英文例句、中文译文、例句来源和许可
learning_tags            学段、CEFR/考试/职业/学术等标签
relations                同义词、反义词、词族、上下位关系
source_records           原始来源、版本、网址、许可证和修改说明
quality                  词条状态、审核人、审核时间和各项质量分
```

公开应用包必须包含一个来源清单和 SHA-256 清单；不能只在界面显示一个模糊的“来自互联网”。商业词典的原文、音频、例句和受限数据库字段不进入公开包。

## 5. 词条生产流程

每一批数据按下面顺序处理，任何一关失败都不进入官方包：

### 5.1 来源闸门

- 固定下载版本或发布日期；
- 保存原始来源链接与许可证原文；
- 判断是可公开分发、仅本地使用还是禁止再分发；
- 为 share-alike、署名、修改说明和音频单独标记；
- 不把牛津等商业内容当作开放数据来源。

### 5.2 规范化

- 统一 UTF-8、大小写、连字符、撇号和英美拼写；
- 去除重复词条和明显乱码；
- 分离原形、词形变化、短语和同形异义词；
- 不把机器生成的中文直接标记为“已审核”。

### 5.3 自写与人工复核

- 中文释义用自己的话重写，保持准确、简洁、符合语境；
- 例句优先自写，或使用许可清楚且能逐条署名的例句；
- 为每个义项至少给出一个能说明用法的例句；
- 对专业词、易混词、介词搭配和语气差异做二次复核；
- 牛津可以帮助个人发现遗漏和比较表达，但不能复制其原文结构、例句或整段解释。

### 5.4 自动检查

- 必填字段、语言方向、编码、长度和 JSON schema；
- 音标和词性格式；
- 英文例句是否为空、是否与词条完全无关；
- 中文释义是否重复、是否包含明显占位文字；
- 许可证字段是否为真实登记值；
- 来源、版本、修改记录和文件哈希是否齐全；
- 是否混入密钥、路径、用户历史或个人文章。

### 5.5 发布闸门

词条状态分为 `draft`、`reviewed`、`published`、`withdrawn`。只有 `reviewed` 且通过许可证审查的内容才可以进入候选官方包；发现来源或质量问题时，使用 `withdrawn` 下架，不直接覆盖历史版本。

## 6. 译学首批词典计划

### A. 当前基线

- 保留当前项目自写 240 条英汉词条，其中 180 条 foundation、60 条带考试/学术阅读覆盖标签；
- 继续支持快速翻译右侧的音标、词性、释义、例句、朗读、收藏、笔记和加入学习；
- 用户导入仍使用英汉 UTF-8 JSON v1；
- 不启动大模型、不联网抓取、不改变当前翻译 Provider 路由。

### B. 第一质量切片：500 条

建议按以下比例制作，不追求空泛的数量：

- 300 条高频日常词；
- 100 条学习、阅读和工作常用词；
- 100 条高频短语、搭配或易混词。

每条至少完成：词性、音标、主要义项、自写例句、自写中文译文、学习标签和来源记录。完成后用固定查询集验证快速翻译的查词、收藏、笔记、加入学习和历史联动。

### C. 第二阶段：3,000—5,000 条

在 500 条切片通过质量回归后，按日常沟通、学校学习、学术阅读、职场表达和考试词汇分包。不同场景使用独立标签和包版本，不把所有内容硬塞进一个不可维护的文件。

### D. 多语言扩展

先保持 `language_pair` 和来源字段，不在英汉首版假装支持其他语言。后续每增加一组语言，都建立独立词包、独立质量样本和独立许可证清单；不因为英文词条结构相同，就默认其他语言的音标、词性和例句规则相同。

## 7. 用户导入体验

普通用户不应该被迫猜“我要导入什么文件”。词典管理入口应提供：

1. **模板下载**：生成带示例字段、许可证、来源和修改说明的 UTF-8 JSON 模板；
2. **导入预检**：导入前显示词条数、语言方向、来源、许可证、是否允许再分发、重复数和错误数；
3. **两种保存范围**：
   - 仅本机使用：只写入用户本地资料库，不进入公开包；
   - 允许随译学发布：只有用户明确拥有再分发权且资料完整时才允许，默认关闭；
4. **来源卡片**：显示词典名称、版本、许可证链接、署名文本和修改记录；
5. **失败原因**：用普通语言说明“文件不是词典包”“缺少许可证”“字段不完整”“编码错误”或“数据不可公开分发”；
6. **安全边界**：只解析允许的文本格式，不执行文件中的代码，不自动访问用户提供的未知网址，不上传词典内容。

当前版本先保留 JSON v1；待大辞典内部 v2 数据结构稳定后，再增加 CSV/TSV 转换向导，避免一开始同时维护多套不一致格式。

## 8. 与快速翻译、学习和模型的关系

词典和翻译模型是两套不同的能力：

- **词典**负责词语解释、词性、音标、例句、搭配和学习资料；
- **翻译模型**负责句子、段落和上下文转换；
- **术语表/翻译记忆**负责用户指定的固定译法和历史复用；
- **学习模块**消费词典、历史和用户标注，负责默写、判题、复习和进度。

所以做大辞典会显著改善“点词学习”和句子理解，但不能单独修复模型的整句翻译错误。快速翻译应继续显示实际使用的 Provider，并把词典来源与模型来源分开显示，避免用户误以为“查到了词典”就等于“模型翻译质量已保证”。

2. 增加内部词条 v2 的来源与质量字段设计，不破坏现有 JSON v1 导入（已完成首版代码结构）；

6. 用固定词条查询集做回归，再决定是否扩充到 3,000—5,000 条；
7. 只有许可、质量和数据包大小都通过后，才放入预览版或正式版安装包。

## 10. 完成标准

- 首批官方词包每条都有来源或自写记录，不能出现无法解释的“网上找来的”字段；
- 许可证和署名可以从词包内追溯到原始页面；
- 公开包不含牛津等商业词典的未授权原文、例句、音频或数据库摘录；
- 导入失败不会写入半成品数据；
- 快速翻译查词、朗读、收藏、笔记、加入学习和历史继续学习都能找到同一条词条；
- 数据包升级不覆盖用户的收藏、笔记、学习记录和个人词条；
- 词典数据和用户隐私默认留在用户选择的本地目录。

## 11. 需要你提供的信息

公开词库路线现在可以直接开始，不需要你上传牛津内容。为了判断牛津是否能进入“个人本地参考层”，后续只需要确认它属于：纸质书、电子书/软件订阅、机构授权，还是带有 API/数据再利用许可的产品；不要把整本词典或账号信息上传到项目里。

## 12. 覆盖目标补充：四六级、考研与考博

### 12.1 覆盖原则

“媲美牛津”在本项目中定义为：在译学助手面向的学习场景里，覆盖足够完整、解释足够清楚、例句和搭配足够可学，而不是复制牛津的版权表达，也不是宣称替代牛津的全部词典产品。

四六级范围以[中国教育考试网的全国大学英语四、六级考试大纲页面](https://cet.neea.edu.cn/xhtml1/folder/16113/1588-1.htm)及其当前发布版本作为覆盖校验依据。考研词汇按当年考试要求和公开官方材料做版本登记，不把商业备考词书的释义、例句和排版当作可复制资料。考博没有一套适用于所有学校和学科的固定词表，必须按招生单位、考试大纲和研究领域建立扩展包；例如辽宁师范大学公布的博士英语大纲把词汇、词组、词义关系、搭配和词根词缀都列为要求，并给出约 8,600 个词和 700 个常用词组的参考规模。[该校博士英语大纲](https://master.lnnu.edu.cn/liaoningshifandaxueboshiyanjiushengyingyuxuekaoshidagang.pdf)

### 12.2 译学词库分层

| 层级 | 面向用户 | 内部目标 | 数据内容 |
|---|---|---:|---|
| YX-CET | 大学英语四、六级学习 | 覆盖官方大纲词目及高频短语，词形合并后形成可学习词条 | 词性、音标、主要义项、搭配、例句、易混提示 |
| YX-Grad | 考研和一般学术阅读 | 在 YX-CET 基础上增加学术高频词、派生词、篇章连接和翻译常见结构 | 学术标签、语域、搭配、英汉互译练习 |
| YX-Doctoral | 考博和科研阅读 | 按学校与学科提供扩展包，不声称有全国统一考博词表 | 科技/医学/社科等领域词条、词根词缀、术语和学术例句 |
| YX-Phrase | 所有学习层级 | 独立维护短语和固定搭配，不把短语错误地拆成单词义项 | 结构、语义、搭配限制、双语例句 |

内部目标先按“可审核的词条数量”推进：YX-CET 约 6,000—8,000 个词条/短语记录，YX-Grad 增加约 2,000—3,000 条，YX-Doctoral 首批增加约 2,000 条通用学术记录，再按专业扩展。上述是项目目标，不是当前已有数据，也不是对任何考试官方词表数量的宣称。

### 12.3 与牛津纸质版的关系

- 用于公开版：不扫描、OCR、批量抄录或逐条改写牛津释义和例句；
- 用于个人学习：你可以自行查阅纸质版并做个人笔记，但个人笔记也不自动成为项目公共数据；
- 用于质量核对：公开词条优先依据许可清晰的开放来源和项目自写内容，不能以“参考牛津”为理由保留牛津的独特措辞或例句结构；
- 用于授权版：只有拿到明确的数据再利用、API 或再分发授权后，才另行设计专门的私有/授权适配器。

### 12.4 新增验收标准

- 每个学习层级能显示自己的覆盖范围、版本和适用人群；
- 同一个词可以同时属于四六级、考研和考博扩展层，但释义、例句和标签按义项管理，不重复复制；
- 考博词包必须记录学校/学科来源，不能显示为“全国考博统一词库”；
- 用户可以只安装或启用需要的层级，词典扩建不会覆盖用户收藏、笔记和学习进度；
- 所有官方包仍必须通过来源、许可证、质量和 SHA-256 闸门。

## 15. 2026-09-15 牛津级目标与数据生产规则

### 15.1 目标定义

“以牛津为目标”定义为面向译学学习场景的质量标尺，而不是复制牛津词典的内容或宣称替代 OUP 产品。每个重要词条逐步追求以下字段完整：

- lemma、词形变化和常见变体；
- 英音/美音音标、词性和可数性等语法信息；
- 分层义项、语域、使用限制、易混词和常见搭配；
- 自写或许可清楚的双语例句、短语和句型；
- 词根词缀、同义/反义、词族和上下位关系；
- CEFR、四六级、考研、学术/专业等学习标签；
- 稳定词条 ID、逐义项来源、许可证、修改记录、质量状态和审核日期。

这是字段和学习体验的目标，不是当前已经完成的覆盖承诺。当前 240 条仍是项目自写质量切片。

### 15.2 四条数据路线

1. **译学自写官方层**：根据公开词目范围和多来源核验，由项目自行撰写中文释义、用法说明和例句；这是默认随包发布的主体。
2. **开放许可补充层**：按固定版本导入 WordNet、Tatoeba 或其他许可证清楚的来源，保留原始许可证、署名、修改说明和来源版本；不同许可证的数据包可以独立发布，不能粗暴合并后重新声明为单一译学许可。
3. **搜索与牛津参考层**：搜索结果、词典网页、纸质牛津和用户个人资料只用于发现候选词、比较用法、发现遗漏和人工复核。不得抓取或照搬定义、例句、音频、排版、数据库字段或整库；搜索摘要本身也不视为可再分发授权。
4. **明确授权层**：只有取得权利人允许的复制、修改、随软件分发和必要语言/地域范围授权后，才建立独立授权词包，并在软件中展示授权范围和到期/撤回信息。

### 15.3 正确性闸门

每批词条进入官方包前必须经过：候选词去重与词形规范化、来源和许可登记、词性/音标核对、义项与语境核对、双语例句人工复核、敏感/乱码/占位文字检查、固定查询集回归和 SHA-256 清单生成。机器生成内容只能标为 `draft`，不能直接标为 `reviewed` 或 `published`。

对容易出错的多义词、介词搭配、专业词和中英不对称表达，至少保留两个独立核验依据；若只有搜索结果或单一机器翻译，不进入 `published`。发现问题时使用 `withdrawn` 和版本修订，不覆盖用户收藏、笔记和学习进度。

### 15.4 可扩展实现

- v2 是词典编辑事实源：来源、许可、义项、例句、关系和质量状态按字段/义项保存；v1 只负责兼容当前快速翻译运行时。
- 公开自写层、开放许可层、用户个人层和未来授权层使用独立包 ID、独立许可证和独立升级记录；用户可以启停或删除个人层，不影响官方层。
- 快速翻译、收藏词库和未来学习页只依赖稳定查询契约，不直接依赖某一个来源；以后增加日汉、英德或专业词包时，只新增语言包和质量回归集。
- 词典、翻译模型、术语表和翻译记忆继续分离：词典提升查词学习，不能把词典数量当作整句翻译准确率。

## 17. 词典总准则（2026-09-15 冻结）

译学词典以“四六级为基础入口，向考研、考博和牛津级质量与覆盖目标持续扩展”为总方向。这里的“牛津级”是对准确性、解释深度、覆盖广度和学习体验的质量标尺，不是复制牛津词典内容，也不是宣称已经完成全部考试词表或商业词库。

### 17.1 一个词条必须能支持理解和学习

单词数量只是基础设施。进入已发布词典的词条，不能只保存一个英文词和一个中文对照，必须逐步具备：

- 词形、常见变体、英音/美音音标、词性及必要的语法信息；
- 按义项分层的中文解释、语境说明、常见搭配、词族、同义/反义和易混提示；
- 语域与语用语气，例如正式、口语、礼貌、委婉、批评、学术或专业限制；这里的“语调”首先指文字使用中的语气和语用，不把音频声学参数混进释义字段；
- 每个核心义项对应的自然双语例句、例句译文和适用场景；发音音频另按来源和许可记录；
- 覆盖层级、领域标签、稳定词条 ID、来源、许可证、版本、审核状态和修改记录。

机器生成的释义或例句只能作为草稿。多义词、介词搭配、专业术语和中英不对称表达必须经过人工语境复核，未通过来源、质量和许可证闸门的内容不能标为 `published`。

### 17.2 从单词向学习图谱扩展

词条是学习图谱的起点，不是终点。后续快速翻译、收藏词库和学习页都应能从一个词继续展开到短语/固定搭配、词族、同反义词、易混词、例句、发音、翻译记录、笔记、收藏和复习任务；这些关系使用稳定 ID 连接，不把学习记录硬写进词典原文，也不因词典升级覆盖用户数据。

因此本项目的词典验收顺序固定为：先保证词条正确，再补全语义层和语用层，再建立例句与关系，最后接入可视化学习、收藏、复习和跨语言扩展。词条总量的增加必须服从这一质量顺序，不能用数量掩盖释义错误或缺少学习上下文。

### 17.3 当前阶段边界

当前运行时词库由 633 条项目自写英汉质量切片和 5,759 条去重后的 CET4/CET6 开放基础词目层组成；其中开放层只提供词目、来源基础释义和覆盖标签，例句、语域、搭配、关系和人工审校仍在建设。它证明的是词典查询和扩展管线，不是完整官方四六级、考研、考博或牛津级大词库。后续要把开放基础层逐条转化为译学富语义质量条目，并持续保留独立来源与许可证边界。
