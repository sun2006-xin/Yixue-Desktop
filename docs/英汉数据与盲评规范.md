# 译学英汉数据与盲评规范

版本：v1
日期：2026-09-11
状态：P1.4 第二阶段执行规范

## 1. 目标

建立可追踪、可重复、不会泄露用户隐私的英汉评测与训练数据流程，用于判断“译学英汉”
微调模型是否真实优于随包 OPUS-MT。当前先建设评测集和盲评工具；训练数据与评测数据必须分开。

## 2. 数据分层

| 层 | 用途 | 模型训练可见 | 是否进入公开仓库 |
|---|---|---|---|
| 固定评测集 | 比较基线与候选模型 | 禁止 | 仅项目原创/可再分发内容 |
| 盲评包 | 人工评分，不显示模型身份 | 禁止 | 默认只保存在本地 |
| 训练集 | 参数微调 | 允许 | 按来源授权决定 |
| 用户纠错 | 个性化与候选训练素材 | 默认禁止 | 禁止；用户明确同意后仍需去隐私复核 |

任何固定评测句及其近似改写都不得进入训练集。训练脚本必须检查数据指纹，发现交叉时停止。

## 3. 来源与许可

每条样例必须具备：

- `provenance.origin`：`project_authored`、`public_domain` 或 `licensed_dataset`。
- `provenance.source_id`：对应本地来源登记项。
- `provenance.redistribution`：当前仓库只接受 `allowed`。
- `contains_personal_data`：固定评测集必须为 `false`。

禁止直接收录商业词典释义、未授权论文正文、字幕、付费课程、聊天记录、会议内容、API 返回的
不明来源语料和任何真实个人信息。牛津等商业词典只能在获得书面授权后作为独立词典包接入，
不能作为当前训练或评测数据来源。

项目原创样例目前只用于私有仓库和内部评测。对外开源数据前，由“花鱼鱼”单独确定数据许可；
程序源码许可不会自动覆盖数据集。

## 4. v2 固定评测集结构

最低 64 条，英译中和中译英各 32 条。四类核心问题每类 16 条，每个方向各 8 条：

1. `completeness`：多分句、否定、条件、时间与指代，检查漏译和增译。
2. `terminology`：软件、AI、学习、阅读和隐私术语，检查固定译法。
3. `academic`：论文语体、因果边界和谨慎措辞，检查语义与自然度。
4. `formatting`：数字、单位、版本号、缩写、占位符和代码片段，检查原样保留。

每条样例必须有唯一 ID、一个方向、至少一个参考译文、一个核心类别和难度等级。格式类必须
声明 `preserve`；非格式类不得用空字符串伪造格式要求。

## 5. 自动校验门禁

校验器必须拒绝：

- 样例数、方向或分类配额不足。
- ID 重复、原文重复、方向非法、参考译文为空。
- 来源未登记、不可再分发或含个人数据。
- 格式类缺少 `preserve`，以及空白保留项。
- 固定评测集与已登记训练集出现规范化文本指纹重合。

校验只证明结构和来源声明符合要求，不证明译文语言质量；参考译文仍需人工复核。

## 6. 双盲评分

基线与候选输出按固定随机种子打乱为 A/B，评分文件不出现模型名和路径。至少两名评审分别按
1–5 分评价：

- 准确性：是否忠实表达全部信息。
- 自然度：是否像目标语言正常表达。
- 术语：关键术语是否准确且一致。
- 格式：声明的符号与格式是否保留。

评分完成后才使用独立密钥文件揭盲。两位评审差值大于 2 分的样例必须复核并记录原因。

## 7. 微调发布闸门

候选模型只有同时满足以下条件才可替换当前 OPUS-MT：

- 在从未参与训练的固定盲评集上，准确性与术语平均分均提升至少 0.25。
- 严重错误数量下降至少 20%，且没有新增长期稳定错误类型。
- 格式保留率不下降。
- 同机 P95 延迟不超过基线 1.25 倍，峰值内存不超过 1.30 倍。
- 双向模型总包体积不超过基线 1.50 倍。
- 模型来源、训练数据摘要、许可证、转换版本、SHA-256 与报告齐全。

64 条固定集用于首轮工程筛选，不足以构成正式版质量声明。发布前还需更大独立集与真实用户
场景测试，但真实用户内容默认不得进入训练。

## 8. 本切片验收

- 新增 64 条、配额平衡的 v2 固定评测集。
- 新增来源登记表与结构/泄漏校验器，并以自动测试覆盖拒绝路径。
- 新增可复现的 A/B 盲评包生成器，输出评分表与单独揭盲密钥。
- 运行 OPUS-MT v2 基线并保存原始结果；不据此直接开始训练。

## 9. 格式保护进展

格式保护已从测试层接入 `QuickTranslationService`，本地 FFI 与可选 API 共用同一保护、回填和
完整性校验路径。真实本地模型链路对 16 个固定格式样例完成 16/16 保留验证，覆盖英中与中英。
该结果只证明路径、URL、版本号、单位、快捷键、代码和占位符不会被模型直接改坏，不替代准确性、
自然度或术语盲评。
