# 译学助手英汉词典包 v1

快速翻译右侧“词语解释”支持导入用户合法取得的本地 JSON 词典包。导入完全在本机完成，词条会写入 D 盘用户数据库；软件不会上传词典内容。

## 给普通用户的说明

词典包是词语解释和学习功能使用的资料，不是翻译模型。它不会把整句翻译能力变强，也不是 Word、PDF、Excel、模型目录或压缩包。

导入步骤：

1. 在快速翻译右侧点击“格式说明与模板”。
2. 点击“保存可编辑模板”，用文本编辑器打开生成的 `.json` 文件。
3. 修改词典名称、真实许可证和 `entries`，并补齐自己的词条。
4. 使用 UTF-8 保存，回到快速翻译点击“导入授权词典包”。

模板只有一个示例词条，结构完整但带有不可导入的许可证占位文字。必须替换为真实许可后才能导入；软件不会替用户猜测或填写第三方许可证。

当前软件自带的是项目自写的 240 条英汉词条，包含单词、音标、词性、释义、英文例句和中文例句；其中新增切片还记录四级、六级或考研/学术阅读覆盖标签。它用于开箱查询、学习功能和界面验证，不是完整的四六级、考研或牛津级大词库。

项目内部同时使用 v2 结构维护可追溯信息。v2 会额外记录稳定词条 ID、词形、词义分层、搭配、学习标签、来源和质量状态；当前运行时仍读取 v1 必填字段，避免在词典扩建阶段破坏已有用户数据库。只有经过许可和质量闸门的 `published` 条目，才允许从 v2 导出为公开 v1 词典包。

## 导入范围

- 文件类型：UTF-8 编码的 `.json` 文件。
- 当前语言方向：`en-zh`，即英汉词典。
- 单个文件最大 100 MB，最多 100000 条词条。
- 必须填写许可信息。请只导入自己制作或已获得合法授权的词典。
- 导入只写入词条，不执行 JSON 中的代码，不访问网络。
- 未修改模板中的示例许可证会被拒绝，避免把占位文字误当成真实授权。

## 最小示例

```json
{
  "schema_version": 1,
  "id": "my-study-dictionary",
  "name": "我的学习词典",
  "language_pair": "en-zh",
  "license": "CC BY-NC 4.0",
  "entries": [
    {
      "word": "inference",
      "ipa": "/ˈɪnfərəns/",
      "part_of_speech": "n. 名词",
      "meanings": ["推理；推断"],
      "example": "The inference is supported by the evidence.",
      "example_translation": "这个推断有证据支持。"
    }
  ]
}
```

`id` 只能使用字母、数字、点、下划线和连字符；每条词条的 `word`、`ipa`、`part_of_speech`、`meanings`、`example` 和 `example_translation` 都必须存在。导入后词条来源会显示词典包名称和许可信息，避免与内置词条混淆。

牛津等商业词典只有在用户拥有明确授权时才能自行导入；项目不会在预览版中捆绑或重新分发商业词典数据。

## 开放词典候选

“免费可下载”不等于“可以无条件随软件分发”。候选数据必须在固定版本、许可证、来源、署名和修改记录都登记后，才能制作成译学官方词典包。候选清单见 `docs/开放词典来源与合规清单.md`。
