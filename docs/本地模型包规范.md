# 译学本地模型包规范

当前版本：1

## 目标

模型目录是外部输入，登记不等于可信。译学只允许加载通过结构、大小、路径和 SHA-256 校验的
CTranslate2 模型包；校验过程只读取数据，不执行模型目录中的程序或脚本。

## 固定目录结构

模型包采用平铺目录，禁止子目录、符号链接和清单外文件：

```text
yixue-model.json
config.json
model.bin
source_vocabulary.json
target_vocabulary.json
source.spm
target.spm
```

CTranslate2 官方转换文档规定核心目录包含 `config.json`、`model.bin` 和源/目标词表：
<https://opennmt.net/CTranslate2/conversion.html>

## 清单示例

```json
{
  "schema_version": 1,
  "package_id": "yixue.opus-en-zh.int8",
  "display_name": "译学英中轻量模型",
  "engine": "ctranslate2",
  "source_language": "english",
  "target_language": "chinese",
  "base_model": "Helsinki-NLP/opus-mt-en-zh",
  "license": "Apache-2.0",
  "files": {
    "config.json": "64位小写或大写十六进制SHA-256",
    "model.bin": "64位小写或大写十六进制SHA-256",
    "source_vocabulary.json": "64位小写或大写十六进制SHA-256",
    "target_vocabulary.json": "64位小写或大写十六进制SHA-256"
  }
}
```

## 安全限制

- 清单最大 64KB，`config.json` 最大 1MB。
- 单文件最大 8GB，整包声明文件最大 12GB，清单最多 32 个文件。
- 文件名必须是当前目录中的普通文件名，拒绝绝对路径、`..`、子目录和符号链接。
- 目录中出现未写入清单的文件即校验失败，避免夹带 EXE、DLL 或脚本。
- 每个声明文件逐块计算 SHA-256，任一不一致即拒绝。
- `config.json` 必须是合法 JSON 对象。
- 当前只接受 `ctranslate2` 引擎，源语言和目标语言不能相同。
- 首版固定使用 SentencePiece，`source.spm` 和 `target.spm` 缺少任意一个都会拒绝。
- SHA-256 只能证明文件与清单一致，不能证明模型来源可信；正式模型还必须审核来源、许可证、
  数据说明和转换器版本。
