# 译学、芝羚文境与觅音的产品边界

更新日期：2026-10-13

## 译学助手

译学当前定位为 Windows 桌面翻译与学习软件，当前交付功能包括快速翻译、截屏翻译、词汇学习和 AI 同传。当前版本的 Windows Release Preview 是本仓库的桌面下载版本。

译学学习板块允许导入 TXT/Markdown，作为本地课程材料使用；通用文档阅读、编辑和用户文章翻译目前不开放。学习板块的内置练习文本和词汇学习仍属于学习功能。译学主导航、源码模块和构建依赖不包含芝羚文境阅读器。

## 芝羚文境（Zhilume Reader）

芝羚文境在独立仓库和独立目录开发、构建与验收。它不属于当前译学 Windows 下载包。只有阅读器自身完成并通过验收后，才另行设计清晰的宿主接口，评估把文章翻译能力接入译学；当前没有该集成能力。

## 觅音（Miyin）

觅音是独立的手机软件，使用独立仓库和发布流程。译学仓库不承载觅音应用，译学 Windows Release 也不打包觅音。

## 平台与发布表述

- 当前对外交付平台：Windows 桌面端。
- macOS：后续计划，不应表述为当前已发布平台。
- 手机端：属于觅音项目，不属于译学桌面产品。
- GitHub Release 使用 Preview 标识，直到相应版本的功能和目标设备验收完成前，不宣传为稳定版。

## 维护规则

1. 译学 README、应用简介和 Release 说明只描述译学当前可用范围。
2. 芝羚文境和觅音的源码、构建目录、用户数据及发布资产保持各自独立，不因译学整理而移动或清理。
3. Reader 集成必须等独立阅读器完成并验收后再通过新 PR 讨论，不将其开发状态描述为译学已具备文章翻译。
