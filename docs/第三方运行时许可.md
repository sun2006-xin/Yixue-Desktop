# 第三方运行时许可记录

本文件记录译学本地推理运行时的固定依赖。正式安装包必须同时携带对应的完整许可证原文；
模型权重的许可证与软件运行时许可证分开展示。

| 组件 | 固定版本/提交 | 许可证 | 用途 |
| --- | --- | --- | --- |
| CTranslate2 | 4.8.2 / `d44d2d069eb88c7b7804da864c10c201501cb4a9` | MIT | CPU INT8 翻译推理 |
| SentencePiece | 0.2.2 / `e0cce7d37b065b5140349dbe12c6bcf6192fdd78` | Apache-2.0 | 本地分词与还原 |

中译英模型发布包保留原项目名称、Helsinki-NLP / OPUS-MT 署名、模型来源、固定提交、
CC-BY-4.0 完整许可原文，并明确说明已转换为 CTranslate2 格式及进行 INT8 量化。

## 补丁边界

译学为 CTranslate2 4.8.2 固定携带 Windows Ruy 退出修补，来源对应上游 PR #2076 的实现思路。
由于当前机器上修补后模型析构仍可挂起，正式架构不依赖该修补保证主程序退出，而使用独立工作进程隔离。

## 发布门禁

- 安装包中保留每个组件的名称、版本、来源、版权与完整许可证。
- 模型详情页展示模型来源、许可证和文件 SHA-256 校验状态。
- 未知许可证、禁止再分发或缺少来源证据的模型不得作为译学官方模型随包发布。
