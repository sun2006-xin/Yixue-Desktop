# 译学自定义主题包 v1

主题包是一个 UTF-8 编码的 JSON 文件，当前只允许颜色令牌。它不执行脚本、不加载网络资源，也不会读取模型或用户数据。

```json
{
  "schemaVersion": 1,
  "name": "清晨纸页",
  "colors": {
    "background": "#F4F8FA",
    "surface": "#FFFFFF",
    "accent": "#2678D9",
    "outline": "#D5E0E8",
    "sidebarTop": "#163C56",
    "sidebarBottom": "#2B8D83",
    "sidebarForeground": "#FFFFFF",
    "sidebarGlow": "#7AE0B2",
    "selectedStart": "#2678D9",
    "selectedEnd": "#42C98B",
    "topStart": "#163C56",
    "topEnd": "#236A78",
    "topForeground": "#FFFFFF",
    "topBorder": "#62BBD0"
  }
}
```

## 制作范围

- `name` 最多 64 个字符。
- 文件最大 1 MB；颜色使用 `#RRGGBB` 或 `#AARRGGBB`。
- 必须提供全部 14 个颜色令牌，缺少或格式错误会拒绝导入。
- 主题图片、字体文件、脚本、远程 URL 和插件暂不支持。
- 导入位置：设置 → 外观与动效 → 导入自定义主题。
- 导出位置：设置 → 外观与动效 → 导出当前主题包。
- 主题偏好保存在用户选择的本地数据目录；恢复官方主题不会删除主题文件。
