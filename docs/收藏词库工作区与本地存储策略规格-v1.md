# 收藏词库工作区与本地存储策略规格 v1

更新日期：2026-09-14

## 目标

在不等待学习模块完成的情况下，先把“已收藏单词”变成一个可独立使用、可继续进入翻译和学习流程的本地工作区。收藏、词典详情和单词笔记继续共用现有 SQLite 数据库，学习模块以后只读取同一套接口，不复制数据。

## 本轮范围

- 收藏单词分页查询：支持搜索、继续加载和空状态。
- 收藏单词详情：词典释义、音标、词性、例句、来源、笔记和学习标记。
- 收藏单词操作：朗读、取消收藏、保存笔记、加入学习、继续翻译。
- 快速翻译学习辅助栏提供“查看全部收藏”入口。
- 预留语言对字段，避免以后增加多语言词典时只按单词字符串混淆。
- 为本地数据容量策略建立统一接口：每类数据可设置“不限制”或用户指定容量，显示估算占用；本轮不自动清理数据。

## 明确边界

- 默认所有用户数据“不限制”，但分页读取有单次请求上限，防止一次渲染拖垮界面；这不是存储上限。
- SQLite 单文件无法精确把物理磁盘页归因到每一张表，因此容量页显示“数据库内容估算占用”，不能伪装成精确磁盘审计。
- 配额达到后不得静默删除旧数据。后续写入应给出可理解提示，由用户提高配额、关闭限制或主动删除数据。
- API 密钥仍只进入系统安全存储；模型文件、缓存和临时文件不归入词库收藏数据。
- 不新增网络服务，不要求 Ollama，不将收藏内容上传或用于训练。

## 数据契约

### FavoriteWordRecord

```text
word                 规范化单词
favorited_at         收藏时间
language_pair        语言对，当前默认 en-zh，供多语言扩展
dictionary_entries   该词的全部本地词典释义、音标、词性、例句和来源
annotation           可为空；包含笔记、加入学习和更新时间
```

### FavoriteWordPage

```text
records              当前页收藏单词详情
has_more             是否还有下一页
```

查询必须使用参数化 SQL，搜索使用字面包含匹配，不能把用户输入拼接进 LIKE 语句。

### LocalStoragePolicy

```text
category             数据类别
quota_bytes          null 表示不限制，否则为用户指定容量
used_bytes           当前数据库内容估算占用
updated_at           策略更新时间
```

首批类别：翻译历史、词典与收藏、学习记录、阅读文档、活动统计、模型目录。模型二进制和缓存实际占用以后通过文件统计单独接入。

## 页面验收标准

- 从快速翻译右侧“已收藏单词”卡片进入独立收藏工作区。
- 收藏页不依赖学习页存在；没有收藏时显示明确的空状态和返回快速翻译入口。
- 搜索、加载更多、刷新和错误重试均有明确状态。
- 点击单词后能看到词典详情；缺词典详情时仍可保留收藏并继续翻译。
- “继续翻译”把单词放入快速翻译输入框，不伪造译文。
- 取消收藏后页面即时移除，重新打开仍保持数据库状态。
- 新旧数据库可自动迁移，旧收藏不丢失。

## 后续接口使用

学习模块只消费 FavoriteWordPage、WordAnnotation 和 TranslationHistory 查询，不直接访问 SQLite 表。复习次数、最后复习时间、间隔重复和学习统计在学习模块中新增，不改收藏页的基础语义。

## 不在本轮

- 完整学习/复习算法。
- 全语言词典内容建设。
- 精确统计模型缓存和每个文件的物理磁盘占用。
- 自动清理、云同步和联网词典。
