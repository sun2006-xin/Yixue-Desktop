# 译学助手联网检索辅助翻译规格 v1

版本：v1
日期：2026-09-14
状态：接口设计，默认关闭

## 1. 结论

本地模型可以借助联网检索提高术语和上下文参考，但“本地模型联网搜索”不是模型自己突然拥有浏览能力，而是译学助手增加一个独立的检索适配器：先按用户允许的范围检索资料，再把经过限制和标记的参考内容交给本地模型生成译文。

联网检索一旦开启，译学助手就不再是纯本地处理。搜索词、选中的句子或用户批准的片段可能发送给网络服务；因此默认关闭，不得静默上传整篇文章、截图、视频字幕、会议内容或个人资料。

## 2. 三种工作模式

### 2.1 纯本地翻译（默认）

- 原文只交给本地翻译模型、词典和术语表；
- 无网络请求；
- 适合隐私文件、工作内容和离线环境；
- 网络不可用时仍保持完整可用。

### 2.2 当前翻译内容联网辅助

- 用户在快速翻译页打开“联网检索”开关后，检索适配器以当前翻译输入自动生成检索请求；用户不需要另填搜索句子，也不会跳转到浏览器；
- 当前输入仍受快速翻译长度上限和隐私边界约束；阅读器全文、截图、视频字幕和会议内容不因这个开关被静默拆分上传；
- 优先查词典、官方术语库、政府/学校/学术站点；
- 搜索结果只作为词义、术语和用法参考，最终译文仍由本地模型生成；
- 适合解决专有名词、学科术语和新词。

### 2.3 用户批准片段辅助

- 用户明确选中一句或一小段后才允许发送；
- 翻译前显示“将发送的内容、目标域名和用途”；
- 不允许默认把全文拆分后逐段联网发送；
- 全文联网属于后续高级功能，需要单独确认和更严格的隐私提示。

## 3. 处理链路

```text
用户输入
  ↓
隐私边界检查：本地模式 / 选中词 / 批准片段
  ↓
检索适配器：允许的 HTTPS 来源、超时、结果数量和长度上限
  ↓
来源整理：标题、网址、时间、版本、术语片段
  ↓
本地模型：带参考上下文生成译文
  ↓
结果门禁：空结果、原文复读、重复、格式破坏、无关内容
  ↓
本地显示与可选缓存：译文、参考来源、检索状态
```

本地模型和检索适配器是两个独立 Provider。没有配置本地模型时，检索结果不能冒充翻译结果；没有开启联网检索时，应用不得偷偷切换到网络翻译服务。

## 4. 隐私与安全边界

- 开关名称必须明确为“联网检索辅助翻译”，不能只写“智能增强”；
- 开启前显示会发送什么，关闭后立即停止新网络请求；
- 快速翻译联网开关开启后，发送当前翻译输入给检索适配器前必须明确显示联网状态；限制输入、结果数和请求时间；
- 对隐私敏感的内容优先使用纯本地模式；用户批准片段模式仍是全文以外的安全选项；
- 搜索来源使用 HTTPS 和可审计的来源清单，初期不做无限制网页爬取；
- 不允许通过搜索结果执行代码、命令、插件或文件操作；网页内容和模型输出都视为不可信文本；
- 过滤或警告 URL 中的本机地址、内网地址、异常跳转和不安全协议；
- 日志只保存检索状态、来源域名、耗时、错误码和结果哈希，不保存密钥和完整私人原文；
- 缓存默认只保存来源元数据和短期结果，用户可以在设置中查看、导出和删除；
- 搜索服务需要 API Key 时，密钥进入系统安全存储，不写入 SQLite、普通配置、日志或导出文件；
- 任何远程服务都不能成为本地隐私承诺的例外，界面必须在结果旁显示“联网参考”标识。

## 5. 质量边界

联网检索可以帮助找到新术语、官方名称、定义和语境，但不能保证译文正确。检索结果可能过时、互相矛盾、断章取义或包含诱导模型的内容。因此结果需要：

- 展示来源和检索时间；
- 区分“词典释义”“网页参考”“模型译文”；
- 多来源冲突时提示用户，而不是自动选择看似权威的单一结果；
- 优先让用户把确认后的译法加入本地术语表；
- 对数字、单位、代码、链接、专名和格式继续执行翻译结果保护；
- 不把联网搜索成功率当成翻译准确率。

## 6. 与当前三板块的接口预留

### 快速翻译

页头显示当前模式：`纯本地` 或 `联网检索辅助翻译`。用户点击开关后，当前翻译请求自动经过检索适配器；界面不提供手动搜索输入框，也不打开浏览器代替翻译。网络状态、实际 Provider 和来源入口可点击查看。

### 模型与服务

把“检索服务”作为独立能力类型，不与“翻译模型”混在同一张模型卡里。用户可以配置本地模型、检索 API 和词典来源，但三者用途分别显示。

### 设置

提供联网总开关、允许的来源范围、片段长度、缓存开关、历史清理和隐私提示。纯本地模式应是一键可恢复的默认选项。

## 7. 分批实现顺序

1. 先完成 Provider 协议和本地模式回归，不发网络请求；
2. 增加由当前翻译输入触发的检索适配器和来源展示；
3. 增加用户批准单句/短片段的预览确认；
4. 增加本地术语表写回与缓存删除；
5. 在固定样本上比较纯本地和联网辅助的质量、延迟和隐私开销；
6. 全文联网、自动网页抓取和视频/会议内容联网放到后续阶段，不能作为首版默认功能。

## 8. 完成标准

- 默认不联网，离线模式可以独立翻译；
- 用户能在开启辅助后看到当前联网状态、发送边界和目标来源；不需要手动填写搜索句子；
- 检索失败、网络断开或本地模型失败都有清晰错误，不静默换路由；
- 来源、时间和模式可追溯；
- 检索结果不执行任何指令，不改变软件权限；
- 密钥、完整私密原文和用户数据库不进入普通日志或导出文件；
- 定向测试覆盖权限开关、长度上限、超时、取消、来源展示、缓存删除和纯本地回退。
