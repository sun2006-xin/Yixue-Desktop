# 译学教材课程包导入规范 v1

日期：2026-09-16
状态：预览版已实现导入与本地保存

## 1. 给用户的最短说明

网上能看到教材，不代表可以复制或再分发。请只导入以下内容：

1. 你自己写的课程；
2. 明确允许下载、修改或本地学习的开放许可内容；
3. 你已经取得合法使用权的学校、出版社、机构或个人资料。

译学不会自动从网上抓取教材，不会把用户导入的教材上传，也不会把用户的商业教材随安装包发布。导入记录会保留来源、版本、许可证/授权说明和权利人，方便用户自查和删除。

## 2. 支持的导入方式

### 标准教材包

- UTF-8 JSON 文件；
- ZIP 或 `.yxtbook` 文件，根目录必须包含 `learning-textbook.json`；
- 清单版本当前为 `schema_version: 1`；
- 最多 200 个课次，包文件最多 50 MB，清单最多 4 MB；
- 原文单课次最多 20,000 字符，词汇最多 1,000 个。

### 普通资料

支持 TXT、Markdown、DOCX 和可以提取文本的 PDF。导入时由用户补充：

- 教材名称；
- 年龄段/学段；
- 学习目标标识，例如 `primary`、`cet6`、`graduate`、`social`；
- 版本/册次；
- 许可证或授权说明；
- 权利人或来源；
- 可选的许可证链接和来源链接（仅 HTTP/HTTPS）。

普通文档作为一个课次进入课程包；后续可用标准 JSON 把一本书拆成单元和课次。

## 3. JSON 模板

```json
{
  "schema_version": 1,
  "id": "my-textbook.en-zh",
  "title": "我的英语教材",
  "age_band": "初中",
  "level": "middle",
  "version": "地区或出版社版本",
  "language": "en-zh",
  "license_name": "请替换为真实许可证或授权说明",
  "license_url": "",
  "rights_holder": "请填写权利人或来源",
  "source_url": "",
  "redistribution_allowed": false,
  "lessons": [
    {
      "id": "unit-1",
      "title": "第一单元",
      "source_text": "A short lesson text.",
      "translation": "一段课文译文。",
      "vocabulary": ["lesson", "text"]
    }
  ]
}
```

`license_name` 和 `rights_holder` 不能保留模板占位文字；否则软件会拒绝导入。`redistribution_allowed` 只是记录权利信息，不会替用户取得许可，也不会改变软件的发布行为。

## 4. 与学习模块的关系

- 课程包显示在“学习 → 教材课程”；
- 课次原文、参考译文和词汇可以直接阅读、朗读、加入学习词书、标记已学；
- 课次进度使用稳定 ID 写入本地学习库，关闭后可以继续；
- 只有当前本地词典已有的词条才能加入词汇复习队列，避免把没有释义和音标的字符串伪装成完整词典条目；
- 词典升级不会覆盖课程包、课次进度、收藏、笔记或复习记录。

## 5. 预览版内置内容边界

预览版只内置译学自写的短课程示例。小学、初中、高中、四六级、考研考博和社会/职场目录是可扩展入口，不代表已经获得任何出版社教材授权，也不代表完整考试词表已经随包提供。

未来接入公开许可教材时，必须同时保存固定版本、来源 URL、原许可证、署名要求、修改记录和再分发判断；不能因为搜索结果能打开就直接复制到安装包。
