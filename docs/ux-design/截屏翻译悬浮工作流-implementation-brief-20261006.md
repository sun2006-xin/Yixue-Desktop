# 截屏翻译悬浮工作流实施设计简报

状态：规格已确认；实施计划待用户评审
日期：2026-10-06
目标平台：Windows 桌面，Flutter UI
关联规格：[截屏翻译常驻入口与悬浮对照框设计规格](../superpowers/specs/2026-10-06-screenshot-translation-floating-workflow-design.md)
关联设计系统：[截屏翻译悬浮工作流设计系统](../designs/截屏翻译悬浮工作流设计系统.md)

## 视觉原则

- 使用译学既有品牌蓝、青绿、新生绿、白色工作面和深海军蓝；不使用有道参考图的珊瑚红。
- 主任务内容清楚，工具控制收敛；不把结果窗做成 AI 聊天窗。
- 对照是结果窗的主层级：OCR 原文和译文并排；截图预览次一级，可展开/收起。
- 全部悬浮控件无持续动画，不遮挡选区，不闪烁，不用虚假进度。

## 组件

- 圆球：44×44 px，圆形点击热区；取景符号居中；悬停显示“截屏翻译”提示；可拖动并贴近屏幕边缘。
- 选区：深海军蓝遮罩、未遮罩选区、青绿色 2 px 边框、八个白心圆拖点；Esc 取消。
- 对照框：初始 560×400 px，最小 420×300 px；白色/主题工作面、12 px 圆角；默认置顶且避开选区。
- 标题栏：截屏翻译标题、状态、置顶、收起、关闭；整条标题区域可拖动。
- 内容区：小幅截图预览；OCR 原文可编辑，译文可选择复制；窄窗使用原文/译文标签切换。
- 底栏：复制译文、重新截取、查看历史。
- 结果状态：识别中、翻译中、完成、无文字、翻译失败；失败保留识别内容并提供恢复操作。

## 行为

1. 圆球点击或系统全局快捷键开始截屏；不切换主窗口。
2. 用户框选并松开后马上回到原应用，系统执行本机 OCR。
3. 识别出文本后自动使用译学现有翻译服务；用户仍可编辑原文并重译。
4. 一个结果窗持续复用；新截屏替换当前内容，已完成记录进入译学历史并带 screenshot_translation 来源。
5. 主窗口关闭时，圆球开启则隐藏主窗并保持服务；圆球关闭则退出应用。
6. 设置可启用圆球和录制热键；快捷键冲突必须显示并允许改键。

## 实施约束

- 由主 Flutter 引擎拥有截屏、OCR、翻译 Provider、历史写入和设置。
- 子窗口通过有会话 ID 的消息与主引擎通信；不得重复创建 Provider 或历史数据库。
- Core SQLite、FFI 和 Dart 历史类型要传递来源标记；旧翻译数据使用 quick_translation 默认值。
- 截图只保留在内存会话，不上传图像、不写历史图片。
- 阅读器页面和分页代码不改动，截屏翻译以独立模块推进。
- 实现验收要包含窗口前后台、多显示器/DPI、Esc、取消、快捷键冲突和退出状态；静态分析或构建不能代替真实桌面行为检查。
