# 截屏翻译工作台 UI 实施简报

**面向：** Flutter 桌面 UI 实施者与审查者

**状态：** 规格审阅前的实现输入；不得据此提前修改产品代码。

**主规格：** [截屏翻译工作台设计规格](../superpowers/specs/2026-10-07-screenshot-translation-workbench-design.md)

**视觉规则：** [工作台视觉系统](../designs/screenshot-translation-workbench-design-system.md)

## 要交付的体验

把当前只有标题、说明和几个按钮的大块空白页面，改为译学自己的截屏翻译工作台。桌面用户能快速开始框选，在原应用继续工作；回到工作台能看到历史、原图、OCR 和译文；想复习时能把原文单词加入“截屏生词”。

## 布局草图

```text
┌ 截屏翻译 ───────────────────────────────────────────────────┐
│ [框选翻译]  Ctrl+Alt+Y  ● 悬浮球已显示  原图自动保存：开  [设置] │
├────────────────────┬────────────────────────────────────────┤
│ 历史记录             │ 原图预览 / 时间 / 复制 / 删除             │
│ 搜索……              ├───────────────────┬────────────────────┤
│ 今天 文章片段        │ OCR 原文           │ 译文               │
│ 昨天 文章片段        │ 可选择单词         │ 可复制             │
│ 更早……              │ 加入截屏生词       │                    │
└────────────────────┴───────────────────┴────────────────────┘
```

此草图表达层级，不要求照搬固定像素。设置入口在当前工作台打开侧面板，显示悬浮球开关/运行状态、快捷键录入、原图自动保存和清理图片。模型与 Provider 仍是共享设置。

## 核心交互

1. 用户从页面、悬浮球左键或系统快捷键开始框选；松开后可拖动八个调节点缩放、框内移动，按 Enter 确认后自动识别与翻译。
2. 结果以独立、轻量、可置顶的浅色窗口出现。用户不必关闭原应用或切换到主窗口才能继续工作。
3. OCR 原文和译文在窗口中清楚并列；用户可修改 OCR 再翻译、复制译文、重新截取、查看历史、置顶或关闭。
4. 用户选择单个英文词，选择菜单提供“加入截屏生词”。未知词可存入，意义需显示词典来源或等待用户填写。
5. 右键悬浮球打开菜单：框选翻译、打开截屏工作台、设置快捷键、关闭悬浮球、退出译学。
6. 关闭主窗口不等同退出：悬浮球开启时主窗口隐藏，浮球继续工作。显式退出会关闭浮球和快捷键。
7. 查看历史文章时，可显式调用“理解与总结”服务生成 AI 学习摘要并复制。只发送当前记录的 OCR 文字，不发送截图；不静默复用翻译 Provider。摘要保存在对应的截屏翻译历史记录中。
8. 用户可在结果窗固定当前截图区域，设置存于本机；之后仅在用户点击刷新时再次采集。若同一运行会话再次采集相同边界，结果窗提示内容是否变化。

## 关键 UI 状态

- 空历史、历史加载中、搜索无结果。
- 悬浮球显示、关闭中、启动失败/可重试。
- 快捷键正常、录入中、已冲突/系统注册失败。
- OCR 进行中/失败、翻译进行中/失败可重试。
- 原图已保存、关闭自动保存、原图保存失败/重试、原图已清理但文本历史保留。
- 生词已加入、非法选词、重复生词、词义尚未填写。

## 内容和视觉约束

- 使用现有 `AppShellColors` 与 Material 主题语义；默认品牌方向是蓝绿、浅色、高可读性。不要把有道截图中的红色按钮或深色工具栏直接照搬进译学。
- 主页面的有效内容占据工作区；避免标题下方留下大片空白。
- 原图预览应与历史条目直接关联；没有图片时提供说明而不是空白占位。
- 用户可选文字；不要用不可选择的纯文本组件渲染 OCR 原文。
- 保持桌面键盘焦点可见，常用动作可键盘访问；关闭和删除提供明确可见目标。
- 所有确认/错误文案用简洁中文，清楚说明“关闭保存只影响以后”“清理图片会保留文字历史”。
- 只实现当前有服务链路的功能；不添加假按钮或未支持的总结、润色、公式提取。
- AI 摘要仅在真实的“理解与总结”服务链路上启用。用户显式触发；请求发送 OCR 原文，不发送截图。摘要写入对应本地历史行，若旧 Core 或数据库写入失败则提示摘要只在当前查看会话保留。
- 固定区域只保存物理坐标，不保存区域画面；刷新由用户显式触发，不做后台取样或自动截图。

## 实施边界

- 需要页面、设置卡片迁移/整合、结果窗口、悬浮球菜单、历史来源过滤、本地截图归档、学习条目可选上下文字段及复习卡呈现协同工作。
- 图片文件由截屏存储服务负责；History repository 负责按来源过滤和删记录；主运行时协调稳定 ID 与文件关联；学习仓储保存 OCR 上下文快照。
- 结果子窗口通过现有窗口协议向主运行时请求加入生词，不直接持有学习仓储。
- 偏好和学习 JSON 向后兼容；旧配置默认启用悬浮球、快捷键沿用现值、原图自动保存默认开启。
- Reader 不在改动范围内。不要把原图二进制存进历史 SQL 行或学习 JSON。

## 审查清单

- [ ] 本页能直接启用/关闭悬浮球、设置快捷键和调整原图保留。
- [ ] 浮球实际可见状态有运行证据，右键每项均能执行。
- [ ] 历史列表只含截屏来源并能分页/搜索；选择条目能显示正确原图与双语文章。
- [ ] 关闭自动保存后，老图片仍在；清理后文字历史仍在；删一条历史后关联图片消失。
- [ ] Provider 收到 OCR 文字且没有图像数据。
- [ ] 词典内外的单词均可加入复习；含义来源不会混淆。
- [ ] 旧版偏好和旧学习文件仍可读取。
- [ ] 以真实 Windows 桌面检查结果窗口、框选边界、浮球状态和典型窄窗口，不只用 Widget 截图代替。
