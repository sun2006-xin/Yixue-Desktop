# 桌面界面动效优化执行说明

## 设计方向

在已确认的深蓝侧栏、蓝色强调、白色双栏工作区基础上，采用“精密工具 + 流动能量”风格。
界面需要有力量感，但不使用大面积霓虹、装饰光球或持续动画。

## 本轮改动

- 删除桌面端常驻底部状态条，回收约 64px 垂直空间。
- 快速翻译页头改为 64px 浮层卡片，标题、处理状态和语言方向形成一个视觉整体。
- “本地处理”做成可点击状态胶囊，版本、数据目录和隐私详情迁入设置页。
- 侧栏项目悬停时使用蓝青渐变、轻阴影和 2px 横向位移；选中态更明确。
- 翻译、清空、粘贴按钮具有 Hover、Pressed、Disabled 四种状态。
- 页面导航后显示 180ms 有限骨架屏，再淡入真实页面，避免空白或硬切。

## 性能与无障碍约束

- 动画时长 90–240ms，只使用颜色、透明度、位移、缩放与阴影。
- 不使用无限骨架动画，不让测试或低性能设备持续重绘。
- 保持键盘焦点、工具提示、44px 最小点击区域和文字对比度。
- 窄屏继续使用底部主功能导航；桌面端底部状态条的删除不影响手机导航。
