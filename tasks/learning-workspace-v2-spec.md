# 译学学习工作台 v2 规格

日期：2026-09-16  
状态：按用户需求进入实现

## Objective

把“学习”从五轨道长页面改为一个清晰的学习计划入口：顶部显示本地真实待复习和今日计划，下面只显示四张卡片——词汇循环、发音跟读、句子练习、文章学习。每张卡片进入独立工作区，返回只回到学习入口并保留当前会话；用户明确退出时才结束会话。

用户覆盖小学、初中、高中、四六级、考研考博、社会人士和进阶英语。教材和文章是内容来源，不额外占用入口卡片。成功标准是四种学习方式都能配置、开始、暂停/继续、复习、记录和恢复，且模型不可用时本地流程仍可用。

## Assumptions and boundaries

1. 待复习数量来自学习队列和本地日期，不硬编码 5810；首次使用由可用词条、目标范围、每日数量和题型设置生成计划。
2. 小学到高中按教材版本/年级/上下册/单元分层；四六级、考研考博和牛津目标按合法词库标签分层。暂无真实数据时显示“待补充”。
3. 文章来源可为网上参考、本地文件、阅读器导入、中文材料或内置自写内容；网络搜索只做用户主动触发的来源入口，不自动抓取或把搜索结果当授权。
4. 商业教材、商业词典、公众号/报刊内容只有在用户有权使用或取得授权时进入本地；不把未经授权内容随安装包发布。
5. 当前麦克风结果只承诺词级识别匹配；AI 总结/评价是可选模型接口，不把模型输出当事实或执行指令。

## User-facing structure

### 学习入口

- 顶部：学习计划标题、待复习数、今日计划、已完成/目标、继续学习、休息/退出。
- 内容：四张等高卡片，每张显示说明、今日目标、当前进度和继续入口。
- 卡片点击进入独立页面；左上角返回不丢状态，退出按钮才清除活动会话。

### 词汇循环

- 顶部介绍和学习配置：学习范围、每日新词、复习数量、题型混搭、计划时间、继续/复习。
- 范围采用可左右翻转的独立卡片：小学学段→年级→上下册→版本/单元，初高中同理，另有四六级、考研考博、牛津/进阶和收藏范围。
- 范围详情显示总量和分页列表；每词显示释义、词性、音标、变形、例句、例句译文、播放按钮和收藏/笔记入口。
- 学习模式支持英译中、中译英、键盘输入、系统随机、顺序、混搭和拓展；达到今日计划后提示完成，可继续、休息或退出，自动保存断点。

### 发音跟读

- 范围只分四六级与牛津/进阶；英式/美式发音可选。
- 单词来源支持系统随机、已学复习、顺序、用户输入中文/英文查词；句子与合法文章跟读共用入口。
- 用户选择今日单词/句子数量；保存继续学习与复习位置，不能每次从头开始。
- 播放官方/词典读音，麦克风识别并给出词级评分；文章跟读保留 AI 评价/总结接口。

### 句子练习

- 先选来源、方向（给中文或给英文）和一星/二星难度。
- 句子拆成词格/小方格，用户用键盘逐格输入或组合候选词块；支持退格、移动、清空和提交。
- 对照合法标准答案，标出错误位置、正确词和句意；保存已练句、继续和复习。
- 句子可来自词典例句、自写/开放题库、用户导入材料或模型生成；模型生成内容必须标明来源和非权威属性。

### 文章学习

- 进入后先选来源：网上参考、本地英文、本地中文、阅读器导入、内置文章。
- 选择文章后进入双栏工作台：左原文，右整篇/段落译文/查词卡/例句/批注，可切换视图。
- 支持画词、框选段落、全文/段落翻译、词典释义、发音、收藏、笔记、心得、AI 大纲/题目/总结和用户自译对照。
- 保存文章来源、译文、当前段落、批注、收藏和学习时间；重新进入默认继续上次位置，明确退出才结束。

### 内容库与数据管理

- 词典/词库、内置文章、导入文章、教材课程包在设置或内容库集中显示：名称、类型、语言、年龄/学段、版本、来源、许可证、更新时间、条目/文章数。
- 历史、收藏单词、句子记录、文章记录、学习进度可分页查看，并支持选择删除和导出；不以页面临时状态替代本地数据库。
- 教材只导入词表、单元元数据或用户合法拥有的内容；课程包使用既有 JSON/ZIP schema，保持可扩展且不执行文件内容。

## Architecture

- `learning_workspace.dart` 负责学习入口状态、共享会话和路由。
- 新增/拆分 `learning_landing_workspace.dart`、`learning_vocabulary_workspace.dart`、`learning_pronunciation_workspace.dart`、`learning_sentence_workspace.dart`、`learning_article_workspace.dart`，每个页面只负责自己的布局和交互。
- `learning_workbench.dart` 继续作为唯一学习状态来源；内容库通过词典、文章和教材服务提供数据。
- 学习计划使用版本化本地对象；学习结果、断点、批注、收藏和来源都由持久化接口保存。

## Testing strategy

- Core/服务单测：待复习计算、首次计划、模式混搭、范围层级、逐词句子评分、断点和删除选择。
- Flutter 交互测试：入口只显示四张卡片；每卡片进入/返回；计划完成/继续/退出；范围配置；文章来源选择；导入和异常状态。
- 回归：`flutter analyze`、带 `YIXUE_CORE_DLL` 的全量 `flutter test`、Windows Release 构建和预览包清单检查。
- 安全：文件大小/字段/URL 限制、来源和许可证提示、导入内容不执行、AI/网页内容按不可信资料处理；不启动大模型做 UI 测试。

## Always / ask first / never

- Always：本地数据可见、可恢复、可按类别删除；异步保存和 UI 状态分离；没有模型时显示明确降级。
- Ask first：新外部在线服务、商业内容随包分发、原始录音保存、真实音素评分依赖和新的模型运行时。
- Never：硬编码待复习总数；把教材第五张卡塞回入口；把网上可见当再分发许可；执行导入文章/模型中的指令；静默删除学习记录。

## Implementation order

1. 学习入口四卡片与共享返回/退出状态。
2. 词汇配置、范围层级、计划摘要和现有复习队列联动。
3. 发音范围/口音/手动查词与现有评分接口联动。
4. 句子词格输入和现有作答记录联动。
5. 文章来源选择与现有文章/教材/总结接口联动。
6. 内容库、历史选择删除、导出与回归发布。
