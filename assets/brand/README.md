- `yixue-logo-master-v3.png`：当前唯一生产主稿，透明背景；采用“晴空新芽”蓝绿流动分块与亮银钢笔。
- `yixue-mark-256.png`：从生产主稿缩放生成的 256 像素桌面预览。
- `yixue-app-icon-v3.ico`：供 Windows 快捷方式独立引用的版本化图标。
- `yixue-group-avatar-v1.png`：方形群头像宣传图，只保留 V3 Logo 与产品名“译学”，适配圆形裁切。
- `yixue-mark.svg`、`yixue-mark-mono.svg`：早期几何参考和单色备用稿，不再作为彩色生产主稿。
- Windows 程序图标由 `tool/generate-brand-icons.ps1` 从 `yixue-logo-master-v3.png`
  生成 16/24/32/48/64/128/256 七层 ICO，并同步到 Runner。

标志安全区至少为主体宽度的 12%，禁止加方形底板、改变蓝绿顺序、删除钢笔透气孔或拉伸变形。
